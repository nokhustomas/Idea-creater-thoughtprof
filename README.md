# 想法推进器 · 试错池

多 AI 会诊系统（想法推进器）的运行产物。每个目录是一次运行，里面有成品、过程记录，以及能找到的验收结果。

> 2026-11-18 整理：本页原写“暂无成品”，现按目录实际内容更新。各运行的结论以目录内记录为准，整理时没有重新运行任何成品。

## 规模

- 62 个运行目录，2026-09-04 至 09-06（加州时间）入库，此后没有更新。
- 题目涵盖：网站（HDIBS 科普站、客户端网页）、交易回测与 T+0 规则、3D 打印件与工程计算、四足步态仿真、商业与研究报告（定价、获客、FPGA×AI 等）、写作与解读（道德经、孙子兵法）、概率计算器。

## 目录约定

- 目录名 = 题目简称_run 编号，前缀表示批次（`mini*`、`命题库`、`正式版` 等）。
- 09-04 的早期目录大多带 `题面.txt`（客户原话）、`验收.md`（机器探针结果）、`过程.md`（各岗位决策摘要）和 `状态.txt`。
- 之后的目录多为 `order_000001/`（成品与 `order_000001_成品.zip`），外加 `成果导读.html`、`决策书.html` 或 `进度交底*.md`。这些目录没有统一的验收文件，结论写在导读和提交说明里。

建池时的规则是“未达标的不进池”，但实际也收入了失败和部分完成的运行。按各目录自己的记录：

| `交易回测_run_0000114` | 未达标：zip 缺样例数据与规则文件 |
| `交易回测_run_0000120` | 未达标：规则永不触发，交易明细为空 |
| `交易回测_run_0000124` | 未达标：后两单没有改代码 |
| `交易回测_run_0000126_M2.7` | 未达标：0 条交易 |

## 密码

网站类成品中的登录密码和 Flask `secret_key` 均为占位符（`CLIENT_PASSWORD_PLACEHOLDER`、`CONTROL_PASSWORD_PLACEHOLDER`、`SECRET_KEY_PLACEHOLDER`），部署前需自行设置。`客户端网页V2_接真机器` 在代码里写了一个默认密码，部署时应通过环境变量 `TJ_PASSWORD` 覆盖。
