## 十、小结（供 v5 定价决策）

1. **Devin/Agent 类月订阅**多在 $20–$500/月区间，是"工具型用户"的对照线（参考他们的支付意愿）。
2. **AI 咨询项目制**多在 $20k–$500k，是"高净值决策者"的对照线（参考他们的客单价）。
3. 我们介于"工具月费"与"咨询项目制"之间，**单项目交付 + 可选月维护**是合理骨架。
4. 真实定价数字以官网为准，本文档所有"待查"标记需在 lookup 后回填。
