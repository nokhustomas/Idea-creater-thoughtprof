# 打印参数表（五边形模块化机身 v3 第一批 3D 打印件）

> 说明：以下参数适用于淘宝常见 FDM 桌面机（成型空间 ≥ 220×220×250mm）。
> 用量/克数为按 PLA 密度 1.24 g/cm³ 估算，标注【估】。
> 所有公差：孔位按 +0.2mm 配合间隙（即 STL 里 8.0 的孔按 8.2 打印，或卖家切片时 XY 补偿 +0.1）。

---

## 1. body_scaled.stl — 1:3 整机空壳

| 项目 | 值 |
|---|---|
| 材料 | PLA（推荐）或 PETG |
| 层高 | 0.20 mm |
| 壁数 | 3 壁（≈1.2 mm） |
| 顶/底层 | 4 层（顶 4 底 4） |
| 填充 | 15% gyroid |
| 支撑 | 需要（十二面体斜面必加树状/常规支撑；底面定位孔可加局部托底） |
| 摆放朝向 | 五边形面水平朝上，最稳的一面向下 |
| 预计用料 | ≈ 120 g【估】 |
| 预计打印时间 | ≈ 6 h【估】 |

---

## 2. face_frame_full_A.stl / face_frame_full_B.stl — 1:1 正五边形面框（半件）

| 项目 | 值 |
|---|---|
| 材料 | PETG（强度好、抗冲击）或 PLA+ |
| 层高 | 0.20 mm |
| 壁数 | 4 壁（≈1.6 mm，最小壁厚不破） |
| 顶/底层 | 4/4 |
| 填充 | 20% grid |
| 支撑 | 仅在 M3 通孔与底面必要时加 |
| 摆放朝向 | 五边形一面贴床（平的一面朝下），分缝朝向操作者方便 |
| 预计用料 | A 半 ≈ 90 g【估】；B 半 ≈ 90 g【估】 |
| 预计打印时间 | A 半 ≈ 4.5 h【估】；B 半 ≈ 4.5 h【估】 |
| 备注 | 拼合面朝上方便对位榫/孔；定位榫凸点在 A 半外侧，凹槽在 B 半内侧 |

---

## 3. module_dummy_A.stl / module_dummy_B.stl — 1:1 假模块（半件）

| 项目 | 值 |
|---|---|
| 材料 | PLA（功能测试件，PETG 也行） |
| 层高 | 0.20 mm |
| 壁数 | 4 壁 |
| 顶/底层 | 4/4 |
| 填充 | 20% gyroid |
| 支撑 | 必须（背面插头凸台 6mm、卡扣舌悬伸需要支撑） |
| 摆放朝向 | 正面朝下贴床（让凸台与卡扣舌朝上，支撑易拆） |
| 预计用料 | A 半 ≈ 130 g【估】；B 半 ≈ 130 g【估】 |
| 预计打印时间 | A 半 ≈ 5.5 h【估】；B 半 ≈ 5.5 h【估】 |
| 备注 | 磁铁位、卡扣舌不要被支撑糊死；支撑设"与模型接触面留 0 层"便于拆 |

## 4. clip.stl — 卡扣舌版（10 个一版）

| 项目 | 值 |
|---|---|
| 材料 | PETG（弹性和耐磨都要） |
| 层高 | 0.16 mm（薄件细点） |
| 壁数 | 3 壁 |
| 顶/底层 | 4/4 |
| 填充 | 40% grid（强度优先） |
| 支撑 | 不需要（本体 3mm 厚，凸点 1.5mm 自支撑 OK） |
| 摆放朝向 | 平的一面朝下，凸点朝上 |

| 预计打印时间 | ≈ 0.5 h【估】 |

---

## 5. 共用打印预设建议（PrusaSlicer / Cura）

- **喷嘴**：0.4 mm
- **第一层高**：0.20 mm
- **回抽**：1.5 mm（直驱）/ 5 mm（远端），速度 35 mm/s
- **打印速度**：外轮廓 35 mm/s、内壁 50 mm/s、填充 80 mm/s
- **温度**：PLA 200/60℃；PETG 235/80℃
- **风扇**：PLA 100%（层 3 起）；PETG 50%（层 4 起）
- **Z 跳接**：开，避免拉丝糊到卡扣舌上

---

## 6. 公差与精度

- 直径孔（磁铁位 Ø8、M3 Ø3.3）：设计 +0.2 mm → 卖家切片 XY 尺寸补偿设 +0.1 mm 即可
- 拼合面（榫/槽）：间隙 0.2 mm，无需额外补偿
- 框平面度：要求 ≤ 0.2 mm，必要时分件打印后在平台上手工砂纸打磨

---

## 7. 安全/工艺硬约束（题面）

- 悬垂 > 45° 处一律加支撑（已在上文"支撑"列说明）
- 最小壁厚 1.6 mm（4 壁 0.4 喷嘴即达）
- 所有零件单件尺寸 ≤ 220×220×250mm（见各 STL 包围盒输出）
- 颜色不限，便于观察分层接缝即可
