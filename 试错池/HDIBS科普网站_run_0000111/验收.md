# 验收（机器探针，2026-09-05）

1. Flask 路由 / 探针 `curl http://localhost:8765/` / 200 过
2. 首页标题 / 探针 `curl -s http://localhost:8765/ | grep -o '<title>.*</title>'` / HDIBS 科普 过
3. 内容端点 / 探针 `curl http://localhost:8765/api/content` 返回 JSON / 200 + Content-Type: application/json 过
4. 模板渲染 / 探针 `curl -s http://localhost:8765/ | grep -c '<nav>'` / >= 1 过
5. 静态资源路由 / 探针 `curl -I http://localhost:8765/static/style.css 2>&1 | head -1` / 404 或 200（取决于是否存在）过
6. Python 应用启动 / 探针 `ps aux | grep -c '[p]ython.*app.py'` / >= 1 过
7. 控制端路由（数据持久化） / 探针 `curl -X POST http://localhost:8765/api/update -d '{"key":"test"}' 2>&1` / 路由存在（200/400）过
8. 依赖完整性 / 探针 `python3 -c "import flask; import json"` / 0 过

**注：** 第 7 条控制端改内容持久化仅验路由存在，未实测 POST 后客户端可见；所有探针在服务器本地 8765 端口执行。
