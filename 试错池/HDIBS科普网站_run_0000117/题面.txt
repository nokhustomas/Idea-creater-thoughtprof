客户需求（客户原话，一字未改）：
我想建造一个网站，用于对贫困学生科普。其中我想设计一个控制端和一个客户端。控制端可以修改、编辑客户端的内容；客户端用于让贫困学生进行访问。我们现在先来解决客户端：客户端首页顶部有一个菜单栏，里面包括了关于我们、社团成员、路径资源三个栏目；首页中间有文字"欢迎，希望你可以在这里燃起你对科学的兴趣。"字样。继续搭建客户端。首先，首页中间的字布局注意一下，"欢迎，"单独占一行。然后，将深色导航栏顶部的"科学之光"改成"HDIBS"。接着，继续完善三个栏目：其中"关于我们"栏目点击跳转后页面中从上往下列出2个小标题，分别是"关于HDIBS"和"历任社长"，每个小标题下面空一段距离；"社团成员"栏目点击跳转后页面留出十个空白的个人信息栏，每个信息栏包括一个照片框和一个写文字的地方；路径资源栏目鼠标移到或点击后不要立刻跳转页面，要弹出一个小菜单，上面有"物理学"、"化学"、"生物学"三个小栏目，鼠标移到或点击任意一个小栏目后也不要立即跳转，而是会弹出另一个更小的菜单，"物理学"的菜单上有"光学"、"力学"、"电学"、"量子力学"、"热学"几个选项，点击任意一个选项后都会跳转到任意一个空白页面。"化学"菜单上有"无机化学"、"有机化学"、"环境化学"三个小选项，点击后会分别跳转一个空白页面；"生物学"的菜单上有"神经生物学"、"其他生物学"两个栏目。在"关于我们"和"社团成员"两个栏目跳转页面的底部都要有返回主页的选项。继续搭建客户端，在进入客户端时加一个密码输入界面，如果输入的密码是"CLIENT_PASSWORD_PLACEHOLDER"，则跳转到桌面，方可正常使用网站，并把密码校验逻辑移到服务端。现在开始搭建控制端，这会和我先前描述的有些出入。控制端会在和客户端相同的登录页面输入密码"CONTROL_PASSWORD_PLACEHOLDER"时跳转。此时会跳转到控制端的首页，首页顶部深色导航栏只有一个选项"进入修改"。首页中间有"欢迎，感谢你对HDIBS作出的贡献。"字样。点击"进入修改"后就可以开始向客户端填写内容了。

补充信息（来自客户与委托人）：
- 受众：贫困地区小学、初中学生。页面必须轻：不用大前端框架，单页体积小，弱网能开；手机优先，电脑也能看；文字用简体中文，浅显。
- 委托人未定其它标准，以下验收即标准。

技术约束：
- Python 3 标准库或 Flask 其一实现服务端（优先 Flask，若不可用则 http.server）；前端纯 HTML/CSS/少量原生 JS；不用 npm/构建工具；不联网也能本地跑。
- 密码校验在服务端（POST），前端不含明文密码。控制端修改的内容持久化到一个 JSON 文件，客户端页面读取该 JSON 渲染。
- 交付为 zip：至少含 app.py（或 server.py）、templates/或 static/ 页面文件、content.json、README.md（三行内启动说明：安装依赖、启动命令、访问地址）。

验收（真伪闸与探针按此判，全部可脚本检查）：
1. 解压后 `python3 app.py` 能在 8765 端口启动（README 写明端口），10 秒内 `curl -s localhost:8765/` 返回 200 且页面含密码输入框。
2. POST 密码 "CLIENT_PASSWORD_PLACEHOLDER" 到登录接口 → 302/200 进入客户端首页；错误密码 → 401 或回到登录页且不含"欢迎"。
3. 客户端首页 HTML 含 "HDIBS"（导航栏）、"欢迎，" 单独一行（"欢迎，"与"希望你可以..."位于不同 HTML 块级元素）、以及"关于我们""社团成员""路径资源"三个栏目文字。
4. 关于我们页含 "关于HDIBS" 与 "历任社长" 两个标题及返回主页链接；社团成员页恰好 10 个信息栏（10 个照片框元素 + 10 个文字区），含返回主页链接。
5. 路径资源为两级弹出菜单（不跳转）：一级含 物理学/化学/生物学；二级 物理学=光学/力学/电学/量子力学/热学，化学=无机化学/有机化学/环境化学，生物学=神经生物学/其他生物学；每个二级项对应一个可访问的空白页（GET 返回 200）。共 10 个空白页。
6. 登录页 POST "CONTROL_PASSWORD_PLACEHOLDER" → 控制端首页，含 "进入修改" 与 "欢迎，感谢你对HDIBS作出的贡献。"；进入修改页可 POST 修改至少"关于HDIBS"正文与社团成员第 1 栏文字，修改后 content.json 变化，且客户端对应页面 GET 能看到新内容。
7. 任一页面 HTML+CSS+JS 合计 ≤ 200KB，无外链 CDN。
8. 以上 1–7 全过才算达标；任何一项用文字说明代替实现即未达标。
