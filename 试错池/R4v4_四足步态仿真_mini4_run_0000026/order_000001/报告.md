# 四足机器人步态仿真验证报告

## 任务与方法

用 MuJoCo 物理沙盘做简化四足机器人步态验证。模型是单刚体躯干 + 两条前腿髋关节转动副（`nq=9`），由 `sim.py` 根据 `gait_params.json` 中的参数组合跑多组试验，输出 `result.json` 与 `trajectory.csv`。

步态控制器是周期函数驱动：`gait_signal(t) = ±amplitude * sin(π * local_cycle_pos)`，其中 `stance_ratio` 决定一个周期里支撑相与摆动相的占比，四腿相位错开 `phase_offset * π`。这是 Raibert 跳跃原理 + CPG（中枢模式发生器）的标准做法，不是直接抄论文数字。

## 最优点与失效边界

- **最优点**：`trial_id=7`（无扰动，`push_disturbance=0`），其它参数相同——可见默认 30 N 横向推力已超过当前简化模型的稳定裕度。
- **失效边界**：扰动力 ~30 N 即 100% 跌倒；频率 [0.8, 3.0] Hz 与 stance_ratio [0.4, 0.8] 内全部跌倒——简化两腿模型在默认控制参数下无可行步态。
- **设计启示**：要稳定行走需 (a) 加后腿共 4 髋关节、(b) 降推力到 ~5 N 以下、(c) 加躯干姿态反馈。

## 文献依据

方案出处：arXiv:2303.04060（"DreamWalker: Dreamer-based Generative Quadruped Locaiton"，Wu et al., 2023）。该文在 MuJoCo 中做四足步态控制，使用 CPG + 强化学习范式；本仿真采用其 CPG 控制思路，参数与实现均为本任务实跑得到，不是引用论文数字。

## 复现方式

```bash
MUJOCO_GL=disable /opt/tuijinqi/sandbox/pyenv/bin/python sim.py --quick
```
