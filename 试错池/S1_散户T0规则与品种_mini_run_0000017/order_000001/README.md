# A股普通散户 T+0 研究交付说明

本目录交付《A股普通散户可执行的 T+0 路径、规则与品种池研究》相关文件，目标是给没有量化接口、通过券商 App 人工点击下单的普通散户作为规则研究和后续离线回测起点，不构成投资建议。

## 研究假设与暂定口径

- 底仓做 T：当日买入股票后可卖出同一股票，次日才能卖出底仓。
- 先卖后买需有真实底仓才能操作，不能裸卖。
- ETF/LOF 按题设免印花税、过户费；实际须以最新基金合同、交易所规则和实际交割单核实。
- 股票 T+0 需要已有底仓，不能把当日新买入股票当作当日可卖底仓。
- 股票涨跌幅暂按主板 10%、科创板/创业板 20%、北交所 30%记录；特殊证券、临停和 ETF 自身规则需逐项核实。
- 佣金暂按默认万 2.5、行业常见水平记录，明确可下调；实际费率、最小收费、免五和费用是否内含以开户券商协议为准。
- 候选池是示例，不代表已满足筛选标准；股票日均成交额、盘口价差、分钟级数据、ETF 跟踪误差/溢价率/规模等均待核实。

## 两条研究路径

1. 持有底仓做 T：先买后卖/先卖后买均需围绕已有可用底仓，普通 A 股受 T+1 约束。
2. 支持 T+0 的 ETF/LOF：只纳入基金合同、交易所规则和券商标识明确允许当日回转的跨境、债券、货币、黄金、商品等品种；普通境内股票 ETF 多数不纳入。

## 交付文件

- `路径对比.md`：两条路径的交易规则、数量限制、交收、费用、涨跌幅/临停、开通门槛、风险和规则来源。
- `品种池标准.md`：股票底仓与 T0ETF 的筛选指标、经验阈值、理由、数据来源、待核标记和候选池规模限制。
- `候选池.json`：不超过 20 条的示例候选池，每条含 `code`、`name`、`type`、`reason` 四键；类型仅限“股票底仓”或“T0ETF”，并逐条写明需核数据。
- `风险与边界.md`：声明、滑点/频率/手续费/追涨等风险、可转债边界及人工点击局限性。
- `需核清单.md`：按高/中/低优先级列出规则、费用、权限、行情、回测和来源待核事项。
- `运行命令.txt`：第一行为带 60 秒超时的完整自检命令。
- `A股T0研究交付包.tar.gz`：包含上述六个研究/验收文件的真实压缩包。

## 使用顺序

先阅读 `路径对比.md` 和 `风险与边界.md`，再按 `品种池标准.md` 使用每日行情数据、分钟级历史数据、盘口快照和公开基金资料复核候选池。完成 `需核清单.md` 前，不得把候选池示例或经验阈值当作买入依据。

## 自检

在当前目录执行：

```sh
head -1 运行命令.txt | sh
```

自检会在 60 秒内检查六个文件存在且非空，并验证 JSON 可解析、候选池不超过 20 条且每条严格包含四键、类型合法。
