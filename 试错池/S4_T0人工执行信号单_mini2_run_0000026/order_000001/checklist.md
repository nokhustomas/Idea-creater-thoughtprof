# T+0 人工执行核对清单（每日盘前打印一份）

> 适用终端：**国信证券 金太阳 iOS 版**
> 适用标的：ETF / A 股
> 用户说明：已有持仓，先卖后买或先买后卖均可；按本清单逐项打勾后下单。

> ⚠️ 这不是投资建议，盈亏自负。

---

## 0. 盘前 5 分钟（09:25 之前）

- [ ] 打开金太阳，确认账户已登录、资金可用额正确
- [ ] 打开今日 `signals_YYYYMMDD.md`，把**底仓做 T**与**T+0 ETF**两栏分开看
- [ ] 对每条信号核对：股票代码、方向、价格区间、数量、止损价、失效时间
- [ ] 把当日计划操作的代码加入金太阳自选股（搜代码→加自选），盘中一键调出

## 1. 开盘下单（按信号单顺序）

每只代码重复以下流程：

### 1.1 买入流程
- [ ] 1) 顶栏搜索框 → 输入 6 位股票代码 → 确认进入该品种页
- [ ] 2) 点 **买入** 按钮（若已有持仓想"先卖后买"，跳到 1.2）
- [ ] 3) 输入 **价格**（在信号单的价格区间内，按对手价/限价）
- [ ] 4) 输入 **数量**（股数，与信号单一致）
- [ ] 5) 委托方式：限价（推荐）/ 市价（仅紧急时用）
- [ ] 6) 点 **确认下单** → 弹出风险提示 → 再点 **确认**
- [ ] 7) 截图保存委托单号或记到账本

### 1.2 卖出流程（底仓做 T）
- [ ] 1) 持仓列表 → 点该品种 → 点 **卖出**
- [ ] 2) 数量输入：要卖股数（不可超过持仓数）
- [ ] 3) 价格：在信号单区间内
- [ ] 4) 委托方式：限价
- [ ] 5) 点 **确认下单**
- [ ] 6) 截图 / 记委托单号

### 1.3 止损单（条件单入口**需核**）
- [ ] 在金太阳「智能委托 / 条件单」里找是否有 **止损单** 入口
  - 有 → 按信号单止损价挂条件单（触发价=止损价），截图确认
  - 没有 → 改为**手动盯盘**：到止损价附近手动市价卖出，并在账本备注「手动止损」
- [ ] 止损单挂好后，在信号单对应行后打勾 ✅

## 2. 盘中纪律（09:30 ~ 14:57）

- [ ] 当日同一标的**最多做 1 轮** T（先买后卖 或 先卖后买），不反复加仓
- [ ] 失效时间到点**未触发即作废**，不追单
- [ ] 触发条件不满足（如价格未到区间）即放弃，不主观预判
- [ ] **当日已做几次** 计数（避免超量）：______ / 3 次

## 3. 收盘复盘（15:00 ~ 15:30）

- [ ] 把今日所有**实际成交**填入 `ledger.csv`（时间,代码,方向,价,量）
- [ ] 未成交的委托：撤销或留单（建议收盘前撤销隔夜单）
- [ ] 运行：`python3 reconcile.py --date YYYY-MM-DD`，生成本日对账报告
- [ ] 报告里重点看：**执行率、平均滑点、当日盈亏**
- [ ] 滑点 > 0.005 元/股 的信号，回头复盘触发条件是否设得过窄

## 4. 隔夜机器对账（可选 cron）

```bash
# crontab -e，每天 15:35 跑一次对账
35 15 * * 1-5 cd ~/work && python3 reconcile.py --date $(date +%Y%m%d)
```

---

## 5. 常见踩坑（国信金太阳 iOS 版特别提醒）

- iOS 键盘遮挡：输完价格后点页面空白处收键盘，再点确认
- 数量输完记得检查单位：**股**还是**手**（1 手 = 100 股）
- ETF（如 510300、510500）支持 T+0：**同一方向当日可多次进出**
- 个股（A 股）：**买入当天不可卖**，必须先有底仓才能做 T+0
- 条件单 / 止损单入口在不同金太阳版本里路径可能不同，**找不到就标"需核"，不要乱点**
