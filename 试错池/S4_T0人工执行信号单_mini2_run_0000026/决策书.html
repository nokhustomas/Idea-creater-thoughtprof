每日信号单应包含哪些字段？

信号单是人工执行T+0的核心依据，字段不全会导致操作失误

精简五要素（mind_mece）

为什么产出它：从MECE分解角度，股票代码、信号方向、价格区间、数量、下单时间是基本要素

优点
  • 覆盖交易最小必要信息
  • 字段少填表快
缺点
  • 缺少触发条件描述
  • 无失效时间字段

因果链：字段少→填表快→执行效率高，但信息不完整→可能错失交易(info_000002)

关键信息：
  • 股票代码6位数字(info_000012)
  • 信号方向用多/空/买/卖描述(info_000013)
  • 价格区间可用绝对数值或百分比(info_000014)

完整六要素（mind_first_principles）

为什么产出它：第一性原理要求分解策略逻辑为基本操作步骤，需含触发条件、价位区间、止损、失效时间

优点
  • 包含触发条件明确买卖点
  • 含止损和失效时间可控制风险
  • 信息完整减少执行偏差
缺点
  • 字段多填表慢
  • 对操作者要求高

因果链：字段全→信息完整→风险可控，但填表慢→执行效率降低(info_000002)

关键信息：
  • 信号单需含触发条件、价位区间、止损、失效时间(info_000002)
  • 需含不是投资建议声明(info_000002)
  • 每只股票≤2条信号(info_000002)
怎么选：如果操作者经验丰富且强调风控选完整六要素；如果追求执行速度且操作者新手选精简五要素

核对清单应细化到何种粒度？

核对清单是执行前最后防线，粒度决定零失误率与操作耗时的平衡

高颗粒核对（mind_mece(need_C)）

为什么产出它：MECE分解要求覆盖持仓检查、资金校验、信号确认、风控检查等项目

优点
  • 逐项打勾确保品种、方向、数量、价格当日次数、止损都核对
  • 零失误率高
缺点
  • 每单核对耗时约3-5分钟
  • 高频交易场景不适用

因果链：粒度细→核对全→零失误，但耗时长→可能错过交易窗口(info_000003)

关键信息：
  • 按国信证券金太阳iOS下单流程：搜代码→买入/卖出→价格→数量→确认(info_000003)
  • 条件单/止损单入口不确定需核(info_000003)

低颗粒核对（mind_milestone）

为什么产出它：从里程碑角度，快速核对是开盘前必要动作，需在开盘前完成

优点
  • 1分钟内完成
  • 适合高频交易
缺点
  • 可能漏核关键项如止损是否挂上
  • 零失误率降低

因果链：粒度粗→速度快→但漏核风险高→可能产生亏损(info_000003)

关键信息：
  • 需核对品种、方向、数量、价、当日次数、止损(info_000003)
怎么选：如果交易频率低但强调零失误选高颗粒核对；如果高频交易且能承受少量失误选低颗粒核对

复盘账本应采用何种记录方式？

账本是复盘和策略优化的数据基础，记录方式影响数据完整性和分析深度

纯手动填写（mind_first_principles）

为什么产出它：第一性原理要求完整记录每笔交易的时间、代码、方向、价格、数量

优点
  • 用户自行记录加深印象
  • 数据结构简单易理解
缺点
  • 依赖用户操作准确性和及时性
  • 可能漏填或错填

因果链：手填→即时记录→但可能出错→需次日对账修正(info_000005)

关键信息：
  • ledger.csv表头需含时间,代码,方向,价,量(info_000008)

机器对照核验（mind_mece）

为什么产出它：从对账角度，机器脚本reconcile.py可对照信号单自动计算滑点、执行率、当日盈亏

优点
  • 自动计算滑点和执行率
  • 客观呈现当日盈亏
  • 减少人为错误
缺点
  • 需次日才能对账
  • 依赖信号单和账本数据都准确

因果链：机器对账→自动计算→数据客观，但需次日→无法实时修正(info_000005,info_000010)

关键信息：
  • reconcile.py对照信号单算滑点、执行率(info_000010)
  • 用户手填ledger.csv(info_000005)
怎么选：如果强调复盘数据客观性选机器对照核验；如果当日就需要复盘结果选纯手动填写

全盘提纯关键信息

  • 信号单每天一份signals_YYYYMMDD.md，每只股票≤2条(info_000002)
  • 核对清单按国信证券金太阳iOS下单流程：搜代码→买入/卖出→价格→数量→确认(info_000003)
  • 信号单分两栏：底仓做T与T+0 ETF(info_000004)
  • 用户手填ledger.csv含时间、代码、方向、价、量(info_000005)
  • A股股票代码统一为6位数字(info_000012)
  • 退出0；signals_sample.md含止损与不是投资建议；ledger_template.csv表头含时间,代码,方向,价,量(info_000008)
