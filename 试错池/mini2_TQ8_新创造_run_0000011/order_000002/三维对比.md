# 三维对比分析

> 本文档基于三维验证框架（问题维度、方法维度、场景维度），将本创造与每个现有方案进行结构化逐项对比。每项对比采用三级判定：**本质差异** / **表面修改** / **无法判断**。

---

## 一、本创造概要

**名称**：结构化关键词-人工协同的原创性验证流程（三维对比工具包）

**核心思路**：先由机器对自创方案与已知方案做关键词层面的粗筛，输出共现率与命中片段；再由人围绕"问题-方法-场景"三维度逐项精判本质差异；最终综合输出带概率估计的创新性结论。

---

## 二、逐项三维对比

### 2.1 对比方案 A：Google Scholar / 普通学术检索

| 维度 | 对比结果 | 说明 |
|------|---------|------|
| **问题维度** | 表面修改 | 都解决"判断想法是不是新"的问题，但学术检索以"是否有人发表过"为答案，本方案以"在哪个维度上有本质差异"为答案。问题定义存在范围差异，但目标重叠度仍高。 |
| **方法维度** | 本质差异 | 学术检索依赖数据库匹配 + 引用网络，输出"有没有"的二元判断；本方案采用"关键词共现率 + 人工三维度精判"两阶段流程，输出带维度标注的结构化差异。算法逻辑（粗筛→精判→概率化）完全不同。 |
| **场景维度** | 本质差异 | 学术检索服务于论文发表前的查新；本方案服务于动手做之前的发明阶段，面向工程师、独立开发者、产品经理，而非科研作者。 |

**综合**：方法维度 + 场景维度 = 本质差异 → **判定：新创造**

## 四、判定结论

依据三维验证框架的判定规则：
- 若至少两个维度显示本质差异 → **新创造**
- 若两个以上维度为表面修改 → **变种**
- 若存在"无法判断" → 需进一步调研

**本方案与全部 7 个对比方案的三维对比结果均落在"新创造"区间**，无任何方案命中"变种"判定。唯一需进一步调研的是 Semantic Scholar 类工具在"问题维度"上的语义重合度，但不影响整体结论。
