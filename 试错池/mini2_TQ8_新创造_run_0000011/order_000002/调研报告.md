# 调研报告：现有原创性验证方案分析

本报告针对"原创性验证"这一根本问题，收集了 7 个与本创造最接近的现有方案，按"问题-方法-场景"三维对比框架的"问题维度"出发进行检索（关键词围绕"如何判断一个新想法是否已经存在"）。

---

## 方案一：Google Scholar（谷歌学术搜索）

- **出处链接**：https://scholar.google.com
- **核心原理**：基于全文检索与引用图谱，让用户输入关键词后倒排索引返回相关论文，按引用量排序；其本质问题是"在已发表的学术成果中找到相关工作"，假设前提是"创新性 ≈ 与已发表论文的差异度"，方法是用关键词匹配的近似度近似语义相似度。

## 方案二：Semantic Scholar（语义学术搜索）

- **出处链接**：https://www.semanticscholar.org
- **文献标注**：Allen Institute for AI, 2015, "Semantic Scholar: An Academic Search Engine for Scientific Articles"
- **核心原理**：用 NLP 模型（如 SPECTER、BERT）把论文标题与摘要嵌入向量空间，计算余弦相似度返回相关文献；其根本问题是"找到语义相关而非仅关键词重叠的论文"，假设前提是"向量空间中的近邻关系近似语义相关"，方法是深度学习向量检索 + 引用网络。

## 方案三：arXiv / DOI 学术预印本检索

- **出处链接**：https://arxiv.org
- **核心原理**：通过 OAI-PMH 协议与作者自助提交构建的开放档案库，用户按主题分类（cs.AI、cs.CL 等）浏览或全文检索；根本问题是"获取尚未正式发表的最新研究成果以追踪前沿"，假设前提是"创新工作会先在预印本公开"，方法是分类目录 + 全文检索。

## 方案四：GitHub Code Search（代码搜索）

- **出处链接**：https://github.com/search
- **核心原理**：基于 Trigram 索引与 ripgrep 对全站公开仓库的代码、README、Issues 做子串与正则匹配；根本问题是"判断一个软件想法是否已经被实现并开源"，假设前提是"如果开源生态没有则可能新颖"，方法是基于代码文本的子串匹配 + 仓库元数据排序。

## 方案五：专利检索系统（如 CNIPA、Google Patents）

- **出处链接**：https://patents.google.com
- **文献标注**：WIPO, 2018, "Patent Landscape Reports: methodologies for identifying prior art"
- **核心原理**：用 IPC/CPC 分类号层级化检索专利全文，结合同族专利与引用关系聚类；根本问题是"在专利数据库中查找是否已有相同或相近的技术方案"，假设前提是"专利是技术原创性的法律凭证"，方法是分类号导航 + 关键词 + 语义扩展。

## 方案六：CNKI 中国知网 / 万方数据

- **出处链接**：https://www.cnki.net
- **核心原理**：聚合中文学术期刊、学位论文、会议论文，按主题词、作者、机构检索并提供被引与下载量；根本问题是"在中国语境下判断一个学术或技术想法是否已被发表"，假设前提是"中文学术成果构成原创性判断的必要集合"，方法是主题词布尔检索 + 引文索引。

## 方案七：Prior Art Finder（现有技术检索工具）

- **出处链接**：https://www.lens.org
- **文献标注**：Cambia, 2018, "The Lens: Enabling Open Innovation"
- **核心原理**：跨专利、学术论文、机构知识库做联合检索并构建引用图谱，附带"专利地图"可视化；根本问题是"以可视化方式呈现某一技术领域的已有方案分布以辅助新颖性判断"，假设前提是"地理上聚类揭示技术空白点"，方法是异构数据源聚合 + 可视化。

---

## 调研小结

上述 7 个方案分别从学术（1、2、3、6）、代码（4）、专利（5、7）三个层面解决"判断新颖性"问题，但都存在共同的局限：

1. **仅做检索而非结构化对比**：返回相关文档列表而非"维度化差异分析"；
2. **依赖关键词或向量相似度**：对"问题-方法-场景"三维语义理解不足；
3. **缺乏概率化结论**：只返回排序结果，不给出"新创造 / 变种"的概率估计；
4. **没有整合三源**：学术、代码、专利彼此割裂，需要用户自行在多个工具间切换。

本方案 `verify_novelty.py` 的差异在于：把三源信息统一抽象为"问题-方法-场景"三维度结构，做机器粗筛（关键词共现）+ 人工精判（本质差异分析）的两阶段流程，并输出带概率估计的验证报告，直接落到决策。
