# 方案_问2 v2

## 核心
本方案帮助创作者系统判断其创造是否为真正的新创新而非变种。通过四维度（问题定义、解决思路、技术实现、适用场景）对比法，将主观判断转化为可操作的结构化检验流程。关键取舍在于：放弃追求绝对客观的评分体系，采用可解释的维度分析加具体案例验证，确保普通人也能独立操作。

运行：`python verify_novelty.py --self my_idea.txt --others existing_solutions.txt`

## 原文
【背景与目标】
本方案服务于“自己发明一个有价值的新创造”这一开放题，帮助创作者在动手做之前先验证想法的原创性，避免将已有方案的简单变种误认为新创造。方案产出为一个原创性验证工具包（含可运行脚本和文档），直接作为idea的四项交付物之一。

【验证框架：四维度对比法】
创新性判断从四个维度展开：问题定义（你解决的是否是不同的根本问题）、解决思路（方法论是否本质不同）、技术实现（算法或数据结构是否有底层创新）、适用场景（是否有实质性的新应用领域）。每个维度用“本质差异/表面修改/无法判断”三级判定。
【文件名：四维度框架.md，内容：定义四个维度的具体含义、评判标准、三级判定规则】
【顺序：先定义维度→再定评判标准→最后定三级判定规则】

【验证步骤】
1. 广泛搜集方案：使用搜索引擎、学术数据库、GitHub等，收集5-10个与你的想法最接近的现有方案，跨领域方法论相近的也要收集。关键词选择从“解决什么问题”出发而非“从什么技术出发”。
【数字来源：5-10个方案，来源于题目要求】
2. 提取核心原理：精读每个方案，撰写一段话说明它“解决什么根本问题、用什么方式、假设什么前提”，避免仅描述界面或参数。
【顺序：步骤1完成后才能做步骤2】
3. 逐维对比：用自己的方案与每个现有方案在四个维度上逐一对比，标注“本质差异/表面修改/无法判断”。
【顺序：步骤2完成后才能做步骤3】
4. 综合判断：若三个以上维度显示本质差异则为新创造；若超过两个维度为表面修改则为变种；若存在“无法判断”则需进一步调研。
【顺序：步骤3完成后才能做步骤4】
【数字来源：三个以上维度、超过两个维度，来源于判定逻辑】
【最容易错的地方：收集方案时只选技术关键词而非问题关键词，导致漏掉本质相同但技术不同的方案。发现这种错误后应回到步骤1重新收集】

【实操工具】
创建verify_novelty.py脚本：读取自创方案描述和现有方案列表，输出四维度对比表格。实现方式：用户预先将方案文本写入文件，脚本用字符串匹配提取关键词并做规则化对比（仅用Python标准库，不依赖NLP库）。
【文件名：verify_novelty.py，内容：接收--self和--others两个文件路径参数，输出四维度对比markdown表格到output/comparison.md】
【验收：python verify_novelty.py --self my_idea.txt --others existing_solutions.txt，退出码0且在output/comparison.md生成表格】
【顺序：先有四维度框架.md才能开发此脚本】
【最容易错的地方：脚本仅做关键词匹配而无法理解语义，会把“音乐推荐系统”和“招聘推荐系统”误判为表面修改（都含推荐），实际需人工核对问题定义维度。发现这种错误后应人工补充判断】

【最容易错的地方】
仅对比表面特征（如界面风格、参数名称、输出格式）而忽略底层逻辑差异。正确做法：必须对比“问题定义是否不同”（比如都是做推荐，你是做音乐推荐还是做招聘推荐这是问题定义的区别）、“算法核心思路是否不同”（同样是排序，你是基于时间还是基于相关度）、“数据流和处理流程是否本质不同”。发现这种错误后应回到步骤2重新提取核心原理。

【交付物】
根据idea要求，本方案本身作为“验证原创性的工具包”，与其他三项（原型、为什么新.md、价值证明、给谁用.md）共同打包。
1. verify_novelty.py：对比分析脚本
2. 四维度框架.md：维度定义和评判标准
3. 调研报告.md：收集的现有方案及核心原理分析【文件名：调研报告.md，内容：至少5个现有方案，每个包含名称、出处链接、核心原理描述】
【数字来源：至少5个，来源于步骤1的5-10个】
4. 四维度对比.md：自己的方案与每个现有方案的逐项对比结果【文件名：四维度对比.md，内容：问题定义、解决思路、技术实现、适用场景四个维度逐项对比】
5. 结论.md：最终判断及依据【文件名：结论.md，内容：新创造或变种的判断结论及四维度分析摘要】
【特别注意：本方案的输出文档（四维度框架.md、调研报告.md、四维度对比.md、结论.md）将作为“价值证明”环节的素材，直接说明本工具如何帮助判断创新性】
【验收（针对交付物文件夹）：ls -la 应显示5个文件，python verify_novelty.py --self my_idea.txt --others existing_solutions.txt 退出码0，output/comparison.md存在】
【顺序：先完成步骤1-4→再生成调研报告.md→再生成四维度对比.md→最后生成结论.md】
