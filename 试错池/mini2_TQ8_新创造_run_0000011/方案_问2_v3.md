# 方案_问2 v3

## 核心
本方案提供一套系统化的原创性验证流程，帮助创作者在动手前评估想法的创新程度。核心是建立"问题-方法-场景"三维对比模型，将新创造与已知方案进行结构化比对。关键取舍在于：机器做粗筛（关键词匹配），人工做精判（本质差异分析），最终产出带概率估计的验证报告。

运行：`python verify_novelty.py --self my_idea.txt --others existing_solutions.txt`

## 原文
【背景与目标】
本方案服务于"自己发明一个有价值的新创造"这一开放题，旨在提供一套可操作的原创性验证流程，帮助创作者在动手做之前判断自己的想法是否具有真正的创新性，而非已有方案的简单变种。方案产出为一个原创性验证工具包，直接作为idea交付物的一部分。

【验证框架：三维对比法】
创新性判断从三个维度展开：问题维度（你解决的根本问题是否不同）、方法维度（核心算法或处理逻辑是否本质不同）、场景维度（应用领域是否有实质性差异）。每个维度采用"本质差异/表面修改/无法判断"三级判定。
【文件名：三维验证框架.md，内容：定义三个维度的具体含义、评判标准（本质差异=问题/方法/场景中至少两个维度完全不同；表面修改=仅参数或界面不同；无法判断=信息不足）、三级判定规则】

【验证步骤】
1. 广泛搜集方案：使用搜索引擎、学术数据库、GitHub等，收集5-10个与你的想法最接近的现有方案。关键词选择从"解决什么问题"出发而非"用什么技术"出发。
【数字来源：5-10个方案，来源于题目要求】
2. 提取核心原理：精读每个方案，撰写一段话说明它"解决什么根本问题、用什么方式、假设什么前提"，避免仅描述界面或参数。
【顺序：步骤1完成后才能做步骤2】
3. 逐维对比：用自己的方案与每个现有方案在三个维度上逐一对比，标注"本质差异/表面修改/无法判断"。
【顺序：步骤2完成后才能做步骤3】
4. 综合判断：若至少两个维度显示本质差异则为新创造；若两个以上维度为表面修改则为变种；若存在"无法判断"则需进一步调研。
【顺序：步骤3完成后才能做步骤4】
【数字来源：至少两个维度、两个以上维度，来源于判定逻辑】

【最容易错的地方】
仅对比表面特征（如界面风格、参数名称、输出格式）而忽略底层逻辑差异。正确做法：必须对比"问题定义是否不同"、"算法核心思路是否不同"、"数据流和处理流程是否本质不同"。发现这种错误后应回到步骤2重新提取核心原理。

【实操工具】
创建verify_novelty.py脚本：读取自创方案描述和现有方案列表，输出三维对比表格。实现方式：用户预先将方案文本写入文件，脚本用关键词共现率计算相似度，输出带概率估计的结果供人工复核。
【文件名：verify_novelty.py，内容：接收--self和--others两个文件路径参数，输出三维对比markdown表格到output/comparison.md】
【验收：python verify_novelty.py --self my_idea.txt --others existing_solutions.txt，退出码0且在output/comparison.md生成表格】
【顺序：先有三维验证框架.md才能开发此脚本】
【最容易错的地方：脚本仅做关键词匹配而无法理解语义，会产生误判，因此必须人工复核。发现这种错误后应在输出中标注"需人工确认"】

【交付物】
根据idea要求，本方案作为"验证原创性的工具包"，与其他三项共同打包。
1. verify_novelty.py：对比分析脚本
2. 三维验证框架.md：维度定义和评判标准
3. 调研报告.md：收集的现有方案及核心原理分析【文件名：调研报告.md，内容：至少5个现有方案，每个包含名称、出处链接（http或文献标注）、核心原理描述】
4. 三维对比.md：自己的方案与每个现有方案的逐项对比结果【文件名：三维对比.md，内容：问题维度、方法维度、场景维度逐项对比】
5. 结论.md：最终判断及依据【文件名：结论.md，内容：新创造或变种的判断结论及三维分析摘要】
【特别注意：本方案的输出文档作为"价值证明"环节的素材，说明本工具如何帮助判断创新性】
【验收：ls -la 应显示5个文件，python verify_novelty.py --self my_idea.txt --others existing_solutions.txt 退出码0，output/comparison.md存在】
【顺序：先完成步骤1-4→再生成调研报告.md→再生成三维对比.md→最后生成结论.md】
