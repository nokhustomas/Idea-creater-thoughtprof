# 本地创意可行性分析器 V2 - 使用场景

## 场景一：独立开发者找方向

**背景描述**：
小李是一名独立开发者，想做一款能提高写作效率的工具，但不确定什么方向有市场。他听说过语音输入、Markdown编辑器这些概念，但不知道哪个组合最有价值。

**使用步骤**：

- **步骤一**：下载并安装本地创意可行性分析器，了解工具功能
- **步骤二**：运行分析器测试几个创意想法：
  - `python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器"`
  - `python3 feasibility_analyzer.py --idea "AI写作助手"`
  - `python3 feasibility_analyzer.py --idea "语音日记应用"`
- **步骤三**：对比各创意的feasibility_score和详细评分维度
- **步骤四**：选择评分最高且独特性(uniquness)不低于0.4的创意进行开发

**预期效果**：
30分钟内完成创意筛选，快速找到技术可行且有差异化的方向。

---

## 场景二：产品经理验证创意

**背景描述**：
张经理在一家SaaS公司工作，老板要求提交一个新功能提案。她需要验证"支持语音输入的协作文档"这个想法是否值得投入研发资源。

**使用步骤**：

- **步骤一**：将创意描述输入分析器：
  ```bash
  python3 feasibility_analyzer.py --idea "支持语音输入的协作文档"
  ```
- **步骤二**：检查可行性评分(feasibility)和可行性维度(feasibility)
  - 如果feasibility < 0.4，说明技术风险较高，需要简化方案
  - 如果feasibility >= 0.4，说明有成熟技术可以借鉴
- **步骤三**：查看related_projects列表，了解直接竞品
- **步骤四**：根据评分和竞品分析，撰写提案决策报告

**预期效果**：
用数据支撑创意评估，减少拍脑袋决策，提高提案通过率。

---

## 场景三：技术博主选题

**背景描述**：
王博主运营一个技术公众号，需要找到读者感兴趣的选题方向。他想写一篇关于"AI辅助编程"的文章，但不确定受众是否真的需要。

**使用步骤**：

- **步骤一**：测试多个相关创意，获取评分对比：
  ```bash
  python3 feasibility_analyzer.py --idea "AI代码补全插件"
  python3 feasibility_analyzer.py --idea "自然语言编程工具"
  python3 feasibility_analyzer.py --idea "智能代码审查助手"
  ```
- **步骤二**：分析各选题的评分差异，关注：
  - clarity：选题描述是否清晰易懂（影响读者理解）
  - uniqueness：是否有新颖角度（影响文章差异化）
- **步骤三**：选择clarity和uniqueness平衡最佳的选题
- **步骤四**：根据feasibility_analyzer输出的相关项目，收集素材

**预期效果**：
精准定位读者感兴趣的选题，提高文章阅读量和互动率。
