# 方案 v1

做一个创意可行性验证器Python脚本，输入创意描述后自动搜索验证并输出报告

运行：`python3 idea_validator.py --idea "你的创意描述"`

1. **idea_validator.py** — 主程序：接收创意描述，调用搜索、分析模块，输出JSON格式可行性报告；文件 idea_validator.py, why_new_demo.py；验收：python3 idea_validator.py --idea "语音控制的markdown编辑器" 退出码为0且输出包含feasible和reason字段
