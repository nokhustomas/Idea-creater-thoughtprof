# 方案 v2

做一个本地创意冲突检测器 idea_conflict.py，输入创意关键词后检索本地知识库并输出冲突度分数

运行：`python3 idea_conflict.py --idea "语音控制的markdown编辑器"`

1. **idea_conflict.py** — 主程序：接收创意关键词，用jieba分词+本地文本检索计算冲突度，输出JSON报告；文件 idea_conflict.py, mini_corpus.txt, why_new.md, value_demo.py, who_use.md；验收：python3 idea_conflict.py --idea "语音控制的markdown编辑器" 退出码为0且输出包含conflict_score字段
2. **mini_corpus.txt** — 本地知识库：1000条常见技术方案摘要（从公开数据集采样），每行一条；文件 mini_corpus.txt；验收：wc -l mini_corpus.txt 输出大于500
3. **why_new.md** — 说明三个最接近方案：GitHub trending、Alfred workflows、VSCode语音插件，给出本创意的差异点；文件 why_new.md；验收：grep -c http why_new.md 输出大于等于3
4. **value_demo.py** — 价值对比实验：分别用本工具和随机词检测同一创意，对比输出分数差异；文件 value_demo.py；验收：python3 value_demo.py 退出码为0且打印conflict_score数值
5. **who_use.md** — 三个使用场景：独立开发者找细分方向、产品经理快速验证创意、技术博主找内容选题；文件 who_use.md；验收：grep -c "步骤" who_use.md 输出大于等于3
