# 方案 v3

做一个本地创意可行性分析器feasibility_analyzer.py，输入创意描述后检索本地技术语料库，输出可行性评分和依据

运行：`python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器"`

1. **feasibility_analyzer.py** — 主程序：接收创意描述，用jieba分词+本地语料检索+多维度评分计算可行性，输出JSON报告；文件 feasibility_analyzer.py, tech_corpus.json, why_new.md, value_demo.py, who_use.md；验收：python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器" 退出码为0且输出包含feasibility_score字段
2. **tech_corpus.json** — 本地知识库：200条GitHub热门开源项目摘要（从GitHub API公开数据采样），每条含name/description/tags；文件 tech_corpus.json；验收：python3 -c "import json; d=json.load(open('tech_corpus.json')); print(len(d))" 输出大于150
3. **why_new.md** — 说明三个最接近方案：GitHub语音项目、VSCode语音插件、语音markdown工具，给出本工具的差异点是'多维度评分+本地离线可用'；文件 why_new.md；验收：grep -c http why_new.md 输出大于等于3
4. **value_demo.py** — 价值证明实验：分别用本工具分析'语音markdown'和随机描述，对比可行性分数差异，证明工具能识别有价值创意；文件 value_demo.py；验收：python3 value_demo.py 退出码为0且打印feasibility_score数值
5. **who_use.md** — 三个使用场景：独立开发者找方向、产品经理验证创意、技术博主选题，每个场景有步骤说明；文件 who_use.md；验收：grep -c "步骤" who_use.md 输出大于等于3

待核实假设：
