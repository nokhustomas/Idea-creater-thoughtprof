## feasibility_analyzer.py
- 文件：feasibility_analyzer.py（主程序）
  - 函数：load_corpus(path) 加载JSON语料
  - 函数：tokenize(text) 用jieba分词
  - 函数：calculate_scores(tokens, corpus) 计算clarity/feasibility/uniqueness三维评分
  - 函数：generate_report(idea, scores) 输出JSON报告
  - 参数：--idea（必需），--corpus默认tech_corpus.json
  - 退出：无错误返回0，异常返回1
- 数据：入 命令行参数--idea，值为创意描述字符串；出 JSON格式报告，含feasibility_score字段，示例：{"idea":"语音控制的markdown编辑器","clarity":0.85,"feasibility":0.72,"uniqueness":0.60,"feasibility_score":0.72,"differences":[...]}；样例 python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器"
- 数字：0.72（由clarity*0.3+feasibility*0.5+uniqueness*0.2公式计算得出，待方案岗确认权重是否合理）
- 数字：0.85（clarity评分=关键词在语料中出现比例，示例中语音控制、markdown均为常见词，识别度高）
- 数字：0.60（uniqueness评分=1-(匹配到的相似项目数/200)，相似项目少则uniqueness高）
- 数字：150（tech_corpus.json最小有效条目数，来源于check条件）
- 步骤 1：安装依赖：pip install jieba（假设环境已有Python3）
- 步骤 2：创建feasibility_analyzer.py文件
- 步骤 3：实现load_corpus函数读取tech_corpus.json，若文件不存在或为空返回默认评分
- 步骤 4：实现tokenize函数用jieba分词
- 步骤 5：实现calculate_scores函数：clarity=关键词在语料中出现比例，feasibility=匹配到的高stars项目占比，uniqueness=1-相似匹配数/总条目
- 步骤 6：实现generate_report函数输出JSON，确保含feasibility_score字段
- 步骤 7：实现argparse解析--idea参数
- 步骤 8：测试：python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器"
- 注意：【易错】jieba未安装会报错，需在步骤中明确安装或假设已装
- 注意：【易错】tech_corpus.json不存在时程序应返回默认评分而非崩溃，若返回默认需确定默认值（当前假设feasibility_score=0.5）
- 验收：python3 feasibility_analyzer.py --idea "语音控制的markdown编辑器" && echo $? 输出0且输出包含feasibility_score

## tech_corpus.json
- 文件：tech_corpus.json（JSON数组文件）
  - 每条：{"name":"项目名","description":"描述","tags":["标签1","标签2"],"stars":数字}
  - 建议用curl从GitHub API获取200条后过滤
- 数据：入 通过curl https://api.github.com/search/repositories?q=stars:>1000&per_page=200获取（假设假设中已说明）；出 JSON数组，至少150条有效description的条目；样例 [{"name":"Julius","description":"Speech recognition engine","tags":["speech","audio"],"stars":2500},...]
- 数字：200（方案中要求获取200条GitHub热门项目）
- 数字：150（check条件要求至少150条有效description（过滤空description后））
- 数字：stars:>1000（假设中说明的API查询参数，筛选高星项目）
- 步骤 1：执行：curl -s "https://api.github.com/search/repositories?q=stars:>1000&per_page=200" > raw.json
- 步骤 2：用Python脚本解析raw.json，提取name/description/tags/stars字段
- 步骤 3：过滤description为空的条目
- 步骤 4：保存为tech_corpus.json，确保>=150条
- 注意：【易错】GitHub API限流导致数据获取失败，需考虑加Authorization header或等待（本题假设API正常返回）
- 注意：【易错】JSON解析错误需检查字段名是否与API返回一致（items/name/description等）
- 验收：python3 -c "import json;d=json.load(open('tech_corpus.json'));print(len([x for x in d if x.get('description')]))" 输出>=150
