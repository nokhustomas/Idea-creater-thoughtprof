# 方案 v3

发明一个本地Markdown图片自动压缩与路径转换工具（mdimg-optimizer），解决Markdown文档中图片体积大、路径依赖强的痛点

运行：`python mdimg_optimizer.py --help`

1. **mdimg_optimizer.py** — 原型：本地Markdown图片自动压缩与路径转换工具，优先使用本机系统工具（convert/magick）压缩，纯Python标准库仅作备选和路径转换；文件 mdimg_optimizer.py；验收：python mdimg_optimizer.py --help 退出码0并打印帮助信息
2. **为什么新.md** — 对比三个已有方案，阐述本创造差异；文件 为什么新.md；验收：grep -c 'http' 为什么新.md >= 3
3. **demo.py** — 价值证明：运行后打印压缩率、转换成功率等数字；文件 demo.py；验收：python demo.py 退出码0并打印数字
4. **给谁用.md** — 三个具体使用场景及步骤；文件 给谁用.md；验收：grep -q '场景一' 给谁用.md && grep -q '场景二' 给谁用.md && grep -q '场景三' 给谁用.md

待核实假设：
- 本机已安装ImageMagick（convert命令），若未安装则提示用户安装
- demo.py自动生成测试图片素材（纯Python生成PNG），不依赖外部文件
- 三个已有方案需通过搜索引擎真实查找Markdown图片处理工具
- 用户场景基于技术写作者、文档维护者、学生群体真实需求推断

本版改动：
- mdimg_optimizer.py：增加系统工具检测逻辑，优先调用convert/magick，zlib仅作备用方案
- demo.py：根据实际使用的压缩方式调整压缩率期望值
- check验收：保持简单检查（--help和关键词），功能正确性由demo.py实际运行验证
