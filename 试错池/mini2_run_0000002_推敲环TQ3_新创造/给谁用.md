# 给谁用 - Markdown 图片优化工具使用场景

## 场景一：技术博客写作者

**用户身份**：独立技术博主或专栏作者，常年在 CSDN、简书、知乎等平台发布技术文章。

**痛点**：
- 文章配图通常是截图或照片，单张图片 1-5MB，整篇文章图片总大小可能超过 10MB
- 平台对图片大小有限制，需要手动压缩后再上传
- 不同平台的图片路径格式不同，文章迁移时图片链接全部失效

**当前解决方案的不足**：
- 使用在线图片压缩工具：需要打开网页、上传、下载，流程繁琐
- 使用 PhotoShop/截图工具压缩：批量处理不方便，参数调整麻烦
- 将图片上传到图床：依赖第三方服务，图片可能因平台政策消失

**使用步骤（5步）**：

1. **准备阶段**：将文章的所有图片放到一个文件夹（如 `article_images/`），确保 Markdown 文件中的图片路径指向这些本地文件。

2. **运行命令**：
   ```bash
   python mdimg_optimizer.py --input article.md --output optimized_article/
   ```

3. **查看结果**：脚本会输出处理报告，显示压缩了多少张图片、总体压缩率是多少。

4. **替换使用**：用 `optimized_article/` 目录下的新 Markdown 文件替换原文件，图片已自动压缩并重新编号。

5. **发布文章**：将压缩后的图片和新 Markdown 文件一起上传到目标平台，或者复制图片 URL 到其他编辑器。

## 场景二：团队文档维护者

**用户身份**：企业内部技术文档管理员，负责维护产品文档、API 手册、开发指南等，需要定期更新和发布文档。

**痛点**：
- 团队成员分散在不同地区，文档中的截图命名随意，路径混乱
- 文档中引用了大量本地图片，团队成员电脑路径不一致导致图片无法显示
- 文档更新频繁，每次更新都需要重新检查图片链接

**当前解决方案的不足**：
- 约定统一的图片存放规范：依赖人工遵守，执行成本高
- 使用企业图床：需要申请权限、配置认证，流程复杂
- 手动复制图片到固定目录：容易遗漏，版本管理困难

**使用步骤（6步）**：

1. **收集文档**：将需要优化的所有 Markdown 文档集中到一个目录（如 `docs_to_optimize/`），图片可以分散在不同位置，但 Markdown 中的引用路径要正确。

2. **统一运行**：
   ```bash
   python mdimg_optimizer.py --input docs_to_optimize/ --output docs_optimized/
   ```

3. **自动处理**：脚本会递归扫描所有子目录，提取所有图片引用，使用 ImageMagick 压缩图片，并生成统一的输出目录结构。

4. **检查报告**：查看输出的压缩率统计，确认图片被正确压缩。

5. **版本控制**：将 `docs_optimized/` 目录提交到 Git 仓库，团队成员拉取后即可使用统一格式的文档。

6. **后续更新**：每次文档更新后，再次运行命令即可自动处理新增和修改的图片。

## 场景三：学生（论文/笔记）

**用户身份**：大学生或研究生，需要写课程论文、毕业设计说明文档，或整理学习笔记。

**痛点**：
- 课程论文要求附图说明，但论文查重系统对图片大小有限制
- 学习笔记中大量截图（代码截图、界面截图），占用大量存储空间
- 需要将笔记分享给同学或上传到云笔记平台，但图片太多导致同步慢

**当前解决方案的不足**：
- 手动压缩每张图片：太繁琐，容易遗漏
- 使用 Word 内置压缩功能：压缩效果有限，无法自定义参数
- 减少截图数量：影响笔记的完整性和可读性

**使用步骤（8步）**：

1. **整理笔记**：将课程笔记或论文的 Markdown 文件和图片放到同一个文件夹。

2. **调整参数（可选）**：如果论文要求图片宽度不超过一定像素，可以用 `--max-width 1200` 参数；如果想更高压缩率，可以用 `--quality 70`。

3. **运行压缩**：
   ```bash
   python mdimg_optimizer.py --input my_notes.md --output compressed_notes/ --quality 75 --max-width 1200
   ```

4. **验证质量**：打开压缩后的 Markdown 文件，检查图片是否清晰可用。

5. **计算节省**：查看压缩报告，例如"压缩率 68%，节省 15MB"。

6. **提交论文**：将压缩后的 Markdown 和图片一起提交，或导出为 PDF。

7. **同步分享**：压缩后的笔记更容易同步到云笔记平台，加载更快。

8. **备份原图**：保留原始图片文件，以备后续需要更高清晰度时使用。
