题目：A 股个人交易规则回测工具（只研究，不下单）

背景：委托人手动交易 A 股约 5 个月，想用数据检验自己的交易规则是有效还是运气。本工具绝不连接任何券商账户、绝不下单、绝不给出买卖建议；只做历史回测与统计。

要交付的成品（能运行的真文件，打包 zip）：
1. backtest.py：命令行工具。用法 `python3 backtest.py --data <csv目录> --rules rules.json --start 2025-01-01 --end 2026-08-31`。
   - 输入行情：本地 CSV（每只股票一个文件，列：date,open,high,low,close,volume），不联网也能跑；自带 sample_data/ 三只股票各 300 个交易日的合成数据用于验收（注明是合成数据）。
   - 输入规则：rules.json，支持至少三类可组合条件：均线交叉（短期/长期天数）、突破 N 日高点/低点、涨跌幅阈值；以及止损/止盈百分比、持有上限天数。A 股约束必须内置：T+1（当日买次日才能卖）、涨跌停 10% 不能成交、手续费按万分之三加卖出印花税千分之零点五计算。
   - 输出到 out/：回测报告.md（总收益、年化、最大回撤、胜率、盈亏比、交易次数、每月收益表）、交易明细.csv（每笔买卖日期价格数量盈亏）、资金曲线.csv（每日净值）。
   - 只用 Python 标准库。
2. rules_example.json：一份示例规则。
3. README.md：五行内说明，第一行写明"本工具不下单、不连接账户、不构成投资建议"。

验收（真伪闸与探针按此判）：
- `python3 backtest.py --data sample_data --rules rules_example.json --start 2025-01-01 --end 2025-12-31` 退出码 0；out/ 三个文件都存在；交易明细.csv 行数 ≥ 6；
- 用一条"永不触发"的规则跑一次，总收益为 0 且交易次数为 0（验证没有幻觉交易）；
- 用一条"每天买入次日卖出"的规则跑一次，交易明细里不存在同一天买入又卖出的记录（验证 T+1）；
- 手续费：任取一笔交易，明细里的费用 = 成交额×0.0003（买）或 成交额×(0.0003+0.0005)（卖），误差 < 0.01 元；
- zip 解开含 backtest.py、rules_example.json、README.md、sample_data/。
不做：实时行情、任何下单接口、任何"推荐"文案。
