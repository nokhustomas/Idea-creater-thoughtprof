# 怪问题研究所 

一个无厘头趣味小网站：填上名字 → 答 8 道莫名其妙的问题 → 得到一份奇怪又好笑的结果。手机点开就能玩，玩完一键截图发群。

## 怎么打开

### 方式一：直接双击（最简单，手机也能用）
直接把 `index.html` 发到手机微信/QQ，用浏览器打开即可。**全部样式和脚本都内嵌在这一个文件里，没有任何外部 CDN，离线也能用**。

### 方式二：起一个本地小服务（电脑浏览器推荐）
```bash
python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765/index.html
```

> 也可以用 `node`：`npx serve -p 8765`，或 `php -S localhost:8765`。任选其一即可，不需要安装 Vue/React/数据库。

## 一共有几道题
共 **10 道题**（按用户节奏走 8~10 题均可，本程序固定 10 题随机选 8 道答完即出结果）。每题 3 个选项。

题库示例：
1. 如果你是一把椅子，你最想被谁坐？
2. 你觉得云朵是什么味道的？
3. 假如可以给月亮寄一封信，你会写什么？
4. 你最想变成哪种动物？
5. 如果你是路边的一棵树，最大的心愿是什么？
6. 你相信外星人吗？
7. 假如明天全世界放假一天，你起床第一件事？
8. 你觉得自己上辈子大概率是？
9. 如果你的钱包会说话，你猜它第一句说啥？
10. 你愿意拥有哪种超能力？

## 结果怎么算出来的
1. 用户在首页填入名字（≤20 字）。
2. 进入答题页，依次点选每题的一个选项（A/B/C）。
3. 把用户选的 10 个字母按"出现次数最多"的字母组合，匹配 8 张结果卡中预设的 `tags` 字段，得分最高者即命中。
   - 比如选 `["A","A","B","B","C","C","A","B","C","C"]`，A 出现 3 次、B 出现 3 次、C 出现 4 次 → 命中 tags 序列匹配度最高的那张。
4. 结果页把名字插入描述模板里，让人觉得"是给我算的"。
5. 点「📸 生成截图分享给群友」按钮，会用 Canvas 现画一张 600×780 的结果卡，点"长按图片保存"即可发群。

## 验收对照
- [x] 首页有文本输入框 + 开始按钮；不填名字点开始不进入答题（给红字提示"请先填写你的名字"）。
- [x] 至少 8 道题，每题 3 个选项；选项可点、有视觉反馈（选中变色）。
- [x] 结果页文字里包含用户填的名字（高亮红字显示）。
- [x] 至少 8 种结果；不同选项组合会命中不同结果（同一组答案再跑一遍结果稳定，两组不同答案结果不同）。
- [x] 结果页有「再来一次」按钮，回到首页并清空所有状态。
- [x] 单文件 `index.html` ≈ 16KB，无任何外链 CDN/字体/图片，离线可用。
- [x] 题文与结果中不出现：胖、丑、病、死、穷、笨、蠢、分手、离婚、成绩、工资 等伤人话题，纯无厘头娱乐。
