决策速览

恶搞小网站开发的三重抉择：技术栈、审查机制、交付方式
技术栈选择
单页HTML
✓ 无需服务器，≤200KB验收无忧
✗ 功能扩展受限，无后端存储
选它若：追求轻量快速上线选它
Python服务器
✓ Flask/Django成熟稳定
✗ 需服务器部署运维
选它若：需存储用户数据选它
关键事实：前端React/Vue，后端MySQL/MongoDB，info_000036-037明确技术栈方向
内容审查
人工+自建词库
✓ 成本可控，灵活调整
✗ 效率低，漏判风险
选它若：预算有限选它
第三方API
✓ 自动高效，覆盖面广
✗ 付费，敏感度不可控
选它若：追求效率选它
关键事实：验收条件7明确禁用词：胖丑病死穷笨蠢分手离婚成绩工资，info_000007/037
交付方式
单index.html
✓ ≤200KB，手机即开即用
✗ 无服务器端逻辑
选它若：轻量首选，info_000005
app.py+templates
✓ 功能完整，可扩展
✗ 需Python环境
选它若：需复杂逻辑选它
关键事实：info_000005给出两种交付标准，info_000006-008为验收依据
