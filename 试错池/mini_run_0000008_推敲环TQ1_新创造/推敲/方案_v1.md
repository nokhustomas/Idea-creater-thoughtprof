# 方案 v1

做一个纯本地运行的文档学习问答工具，扫描指定文件夹的文本文件建立索引，用户提问时用关键词匹配+简单相似度返回最相关的片段

运行：`python doclearn.py --path ./sample_docs --query "什么是Python"`

1. **原型程序** — doclearn.py：扫描文件夹读取txt/md/py/json文件，建立倒排索引，用户查询时返回最相关的文件片段；文件 doclearn.py, sample_docs/sample1.txt, sample_docs/sample2.md；验收：python doclearn.py --path ./sample_docs --query "测试" 退出码为0且有输出
2. **为什么新.md** — 对比三个现有方案（ChatGPT API、LangChain、Obsidian插件），说明本工具纯离线、零依赖、轻量级的差异；文件 为什么新.md；验收：文件包含三个方案名称且每个有http链接或文献标注
3. **价值证明** — demo.py：对比本工具与直接grep搜索的效果，统计查找相关内容的准确率和耗时；文件 demo.py；验收：python demo.py 退出码0且打印至少一组数字
4. **给谁用.md** — 三个场景：1.离线写作时查笔记 2.开发者查自己的代码库 3.学生整理学习资料；文件 给谁用.md；验收：文件存在且包含三个场景步骤说明
