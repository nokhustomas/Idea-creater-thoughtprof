# 为什么新：Snippet Knowledge Graph Builder

## 最接近的三个已有方案

### 1. SnippetsLab (https://www.snippetslab.com)
- **做法**：macOS专属应用，需要手动创建收藏集、手动添加标签
- **差异**：本工具自动从代码内容提取主题，无需手动分类

### 2. GitHub Gist (https://gist.github.com)
- **做法**：云端存储代码片段，基于文件名和描述搜索
- **差异**：本工具构建双向知识图谱，自动发现片段间的关联关系

### 3. VS Code Snippets (https://code.visualstudio.com/docs/editor/userdefinedsnippets)
- **做法**：基于特定编程语言的代码补全片段，需要手动定义前缀
- **差异**：本工具支持多语言、跨语言发现主题、自动生成知识图谱

## 本创造的独特价值

- **自动主题提取**：无需人工标签，工具从代码AST和关键词自动识别主题
- **双向链接图谱**：片段之间自动建立关联，形成可导航的知识网络
- **模糊重复检测**：使用SequenceMatcher检测相似片段，避免知识冗余
- **零依赖离线运行**：纯Python标准库，无需安装额外包
- **交互式浏览器**：一键生成可搜索的HTML知识库界面
