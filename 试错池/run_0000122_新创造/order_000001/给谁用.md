# 给谁用：Snippet Knowledge Graph Builder

## 场景一：个人代码笔记整理

**用户**：有大量零散代码片段的独立开发者

**使用方法**：
1. 将所有 .py/.js/.sh 文件放入 `snippets/` 文件夹
2. 运行：`python snippet_harvest.py snippets -o output`
3. 打开 `output/browser.html` 查看交互式知识库
4. 在浏览器搜索框输入关键词，快速找到相关代码片段

**效果**：原本分散的代码自动按主题分类，形成可导航的知识网络

---

## 场景二：团队代码资产盘点

**用户**：需要整理历史代码库的小型开发团队

**使用方法**：
1. 收集团队成员的示例代码（Python/JavaScript/Bash等）
2. 放入 `snippets/` 目录
3. 运行：`python snippet_harvest.py snippets -o team_kb`
4. 查看 `team_kb/knowledge_graph.md` 获取完整概览
5. 打开 `team_kb/data.json` 供其他工具使用

**效果**：发现代码重复、统一命名规范、建立共享代码库

---

## 场景三：学习笔记整理

**用户**：编程学习者，需要整理教程代码

**使用方法**：
1. 将学习过程中写的示例代码分类放入 `snippets/`
2. 运行：`python snippet_harvest.py snippets -o learning_kb`
3. 查看HTML浏览器，按主题浏览代码
4. 标记相似的重复代码，理解不同实现方式

**效果**：将零散的学习代码变成结构化、可检索的知识库
