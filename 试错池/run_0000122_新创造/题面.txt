题目：自己发明一个有价值的新创造（开放题）

要求：不指定领域。由系统自己判断"什么东西现在还没有、做出来有人会用"，然后真的把它做出来。
不许：网页模板、hello world、把已有工具换个名字、只写方案不做实物。

要交付（真文件，全部打进一个 zip）：
1. 原型：能在本机运行的程序或工具（Python 标准库或本机已装工具），附一条运行命令，运行后有可观察的输出或文件。
2. 为什么新.md：最接近的三个已有方案各一段（名称、出处链接或文献、它们怎么做），再写本创造与它们的差异各一句。
3. 价值证明：一个能运行的小实验或对比脚本（demo.py 或 bench.sh），运行后打印一组数字或生成一个文件，直接说明"比现有做法好在哪/省了什么"；实验数据要能复现。
4. 给谁用.md：三个具体使用场景、每个场景一步一步怎么用，不超过一页。

验收（机器按此判，全部可脚本检查）：
1. zip 解开含上述四项；原型运行命令退出码 0 且产生输出或文件；
2. 为什么新.md 里有三个方案且每个带 http 链接或文献标注；
3. demo.py/bench.sh 退出码 0 并打印至少一组数字；
4. 全部文件在 30 分钟内可跑完；不联网也能跑（联网只允许在"为什么新"的资料收集阶段）。
