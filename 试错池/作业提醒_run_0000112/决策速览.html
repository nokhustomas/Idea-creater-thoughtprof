决策速览

构建ics文件读取系统，选择运行环境和解析库
运行环境选择
本地Python脚本
✓ 零部署成本，适合个人订阅
✗ 需手动运行，跨平台维护
选它若：无服务器、无IT支持、零运维预算、零合规审查
云函数
✓ 定时触发免运维，适合小规模
✗ 冷启动，ics远程拉取频次受限
选它若：可接受上云、少量云服务预算、学生数据合规
自建服务器
✓ 最自由，适合学校侧
✗ 需运维、ip白名单或代理
选它若：已拥有VPS或校内服务器，愿做基础运维
家长群晖/NAS家庭服务器
✓ 兼顾本地与持续运行，适合多孩家庭
✗ 需具备docker知识
选它若：家庭有群晖/威联通等NAS，NAS上能装docker或Python
学校IT统一平台
✓ 覆盖最广，适合校级推送
✗ 需校方IT配合、隐私合规审批
选它若：面向学校级别，需走校方IT通道、合规审批
GitHub Actions
✓ 零预算、零运维，适合轻量提醒
✗ cron精度有限，隐私边界须自查
选它若：为学生/教师个人，接受GitHub第三方数据合规条款
关键事实：无服务器、无IT支持、零运维预算、零合规审查
ics文件解析库选择
icalendar库
✓ Python标准库，功能成熟
✗ 无
选它若：Python开发环境
关键事实：Python开发环境
