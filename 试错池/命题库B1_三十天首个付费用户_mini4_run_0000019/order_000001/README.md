# 30天拿到第一个付费用户 · 快餐类餐饮代运营

## 项目说明
本工作目录实现"30天0成本为快餐类餐饮小微企业主提供小红书/抖音代运营服务，拿到第一个付费用户"的完整执行方案。按天拆分为7个阶段，每阶段都有真实可交付的文档。

## 前提假设（客户原文中明确要求假设，并在本README里写明）
1. **快餐类小微企业主确实愿意为代运营付费**（需进一步验证）——这是整个商业模式的根基，若不成立则方案需重构。
2. **免费案例店家愿意书面同意展示**（需电话确认）——若店家不愿意签书面同意，则案例无法公开宣传，需重新物色店家。
3. **小红书/闲鱼发帖不被删**（若被删用备用方案）——若平台判定营销号限流/删除，立即切换到大众点评商家号、知乎、微博等备用渠道。
4. **AI生成的账号定位和内容规划质量能满足店家实际需求**（若不达标用人工代写补充）——AI生成后必须人工二次加工，去掉套话、加入餐饮行业接地气表达。
5. **大众点评商家号0成本可完成注册**（需核实是否需要营业执照）——截至调研时点，餐饮类商家号注册需提供营业执照，若无证则改用小红书/抖音/知乎等不需要营业执照的个人账号方案。

## 资金/技能背景分情形
- **0资金场景**：仅有一台Mac + AI订阅（ChatGPT/Claude）——本方案就是为此场景设计。
- **0技能场景**：无营销经验——按本方案 SOP 即可执行；关键技能要求会用 AI 工具 + 基本小红书/闲鱼发布流程。
- **时间投入**：约 30 天内每天 2-3 小时（白天引流+晚上内容生产）。

## 数据真实性说明
所有"调研样本"和"竞品数据"是基于公开平台（大众点评、小红书、闲鱼、淘宝、美团、抖音）公开可见信息的整理归纳，已尽量贴近真实市场行情。联系方式为脱敏虚构（用于演示跟进流程），不应理解为真实可联系店家。案例文档中的店家（张姐、老陈）为基于真实市场存在的小餐饮店主画像构建的演示案例。
