# 备用引流方案

**用途**：主渠道（闲鱼 + 小红书）若被限流/删除/效果不佳，立即切换。  
**触发条件**：闲鱼商品 7 天曝光 < 200 或小红书笔记单篇阅读量 < 100。

---

## 备用渠道 1：大众点评商家号

### 注册条件（核实结论）
- **需要营业执照**（截至 2024-12 调研时点，餐饮类商家号注册须提供营业执照）。
- **0 成本场景下的绕过方案**：用身边朋友（已开餐饮店、有营业执照）的商家号代发笔记，注明「运营顾问合作」即可。
- 若身边无餐饮营业执照朋友 → 跳过此渠道，改用渠道 2/3。

### 引流路径（到微信）
1. 商家号发笔记：标题带「想找代运营/想学小红书的老板可以私信我」
2. 用户私信 → 回复话术：「我整理了一份《餐饮老板小红书定位模板》，加我微信发你」
3. 微信承接 → 私域运营

### 平台到微信的导流路径（关键合规点）
- 大众点评允许在商家号私信中回复联系方式（如微信号）。
- 不要在笔记正文里直接贴微信号（违规），私信中可发。
- 1 对 1 私信上限：每天 ≤ 30 条陌生用户，避免被判定骚扰。

## 备用渠道 2：知乎

### 注册条件
- 0 成本，个人账号即可，无需营业执照。

### 选题方向（针对餐饮老板）
- 「餐饮老板想做小红书，应该怎么起步？」
- 「快餐店引流有什么低成本方法？」
- 「找代运营和自建团队哪个划算？」

### 引流路径（到微信）
1. 回答以上问题 → 文中植入「我帮 2 家快餐店从 0 做小红书，真实数据见想法」
2. 想法区发「案例数据图」
3. 评论区互动：「想看完整案例数据可以私信我」
4. 私信回：「完整文档在我微信，加我发你，备注知乎来的」
5. 微信承接 → 私域运营

### 注意事项
- 知乎正文里**不可直接贴微信号**（违规），必须走私信。
- 知乎 1 对 1 私信每天上限 ≈ 50 条陌生用户。
- 知乎用户决策周期长（5-15 天），作为长尾补充渠道。

## 备用渠道 3：微博

### 注册条件
- 0 成本，个人账号即可。

### 选题方向
- 行业话题：「#餐饮老板做自媒体」「#快餐店引流」超话
- 互动形式：发起投票「你是快餐老板吗？想让顾客主动找上门吗？」

### 引流路径（到微信）
1. 微博正文：「想看 2 个快餐店 14 天 1000 阅读的真实案例？」
2. 评论：「完整文档在评论区第一条」
3. 评论第一条：「链接打不开的话可以加我微信（写在评论区置顶）」
4. **注意**：微博个人简介里**可以挂微信号**（合规通道），用「微信号：xxx」格式即可。
5. 微信承接 → 私域运营

### 注意事项
- 微博比知乎导流路径短（个人简介可直接挂微信号）。
- 微博用户偏年轻女性，与餐饮老板画像匹配度一般（二线）。

## 备用渠道 4：抖音同城号（个人账号 0 成本）

### 注册条件
- 个人账号即可，0 成本，无需营业执照。

### 内容方向
- 「探店 vlog 形式的代运营教程」
- 「30 天陪跑一个餐饮店的全过程」

### 引流路径（到微信）
1. 视频里说：「评论区扣 1，我发完整定位模板」
2. 评论区互动 → 私信 → 「加我微信发你完整文档」
3. 抖音主页简介里**可以挂「商务合作」入口** → 跳转微信。

### 注意事项
- 抖音同城号起号快（3-7 天可见），但内容生产成本高（需拍视频）。
- 若已有抖音账号 → 第 1 优先级。

## 主渠道被删后的切换 SOP

### 触发：闲鱼商品 7 天曝光 < 200
1. 立即换标题（去掉「2 个案例」具体数字，改为「真实案例可查」）。
2. 重发新商品（最多 2 次/天）。
3. 同时启动抖音同城号 + 知乎。

### 触发：小红书笔记被限流（阅读 < 100）
1. 检查是否含敏感词（代运营、推广、加微信）。
2. 删除重发，标题/正文做改动（≥30%）。
3. 同时启动知乎 + 微博。
