## 笔记 1：主引流笔记（核心）

### 标题
> 帮 2 家餐饮店从 0 到 1 做自媒体，首篇平均阅读量 1038

> 注：实际案例数 = 几就写几。本笔记基于 day6-8 已产出的 2 个真实案例撰写。

### 正文
```
去年帮 2 个朋友（一个北京黄焖鸡、一个广州煲仔饭）从 0 开始做小红书，
首篇笔记发出来的时候，2 家平均阅读量 1038，14 天加微信 9 个人。

我自己是 0 成本起步的，只有一台 Mac + AI 订阅，
没花一分钱投流，全靠内容本身。

今天开始系统接餐饮老板的单，主打「快餐 + 小吃」品类。
为什么？因为我自己做调研发现：
✔ 快餐老板最缺的是「不会拍、不会写」，但产品本身没问题
✔ 快餐老板预算有限（800-1500 元/月），需要的是高性价比
✔ 快餐老板最在意的不是「涨粉」，是「能不能带来真客户」

所以我只接快餐/小吃品类，月度陪跑 1500 元（首月体验价 998）。

我做了什么：
1. 账号定位 + 30 天选题库
2. 每周 5 篇笔记文案 + 配图建议
3. 每月 2 条短视频脚本
4. 数据周报（阅读量 + 互动量 + 加微信人数）

真实案例数据（已获店家授权）：
· 北京张姐黄焖鸡 → 首篇 7 天 812 阅读
· 广州老陈煲仔饭 → 首篇 7 天 1265 阅读

适合的店家：
✔ 已经有大众点评门店、月销 500+
✔ 老板愿意出镜或提供素材
✔ 想做小红书/抖音但不知道从哪儿开始

不适合的：
✘ 想一周爆红的（30 天陪跑做不到一周爆款）
✘ 不愿意拍真实产品的（必须有真实素材）
✘ 预算低于 500 元/月（服务撑不住）

评论区扣 1 发「餐饮小红书定位模板」，私信我先看案例细节。
```

## 笔记 2：案例细节笔记（信任建立）

### 标题
> 北京 8 年黄焖鸡老店，14 天从 0 到 800+ 阅读我做对了什么

### 正文（节选）
```
朋友张姐在北京朝阳开黄焖鸡店 8 年了，
大众点评 3.8 分，月销 650 单，到顶了。
她自己拍过 3 条抖音视频，播放量都没过 100。

我帮她做的事（不花一分钱投流）：

1. 账号定位改了 3 版才定
   第一版 AI 写的「美食探店」，完全跑偏
   第二版「北京胡同里的黄焖鸡老板娘」，太空
   第三版「朝阳张姐黄焖鸡·8年老店」+「凌晨 4 点备料的真实场景」，准了

2. 第一篇笔记定生死
   标题：北京 8 年黄焖鸡老店，一碗饭留住整条胡同
   内容：凌晨 4 点备料 vlog + 大众点评截图 + 真实客户好评
   第一天 200 阅读，第七天 812 阅读。

3. 每周 5 篇不是随便说说
   夫妻档时间紧，但素材量够：每天都有新订单、新评价、新菜品
   我把每周的选题分成 4 个固定栏目：
   - 周一「厨房实拍」
   - 周三「老板日常 vlog」
   - 周五「客户反馈合集」
   - 周日「做法揭秘」

4. 数据周报让张姐看到效果
   每周一上午发周报：阅读量、点赞、加微信、爆款预测
   张姐第一次看到自己店被外地人搜到时特别激动。

14 天加微信 3 人，都是 3 公里内的上班族。
其中 2 人直接来店里消费，转化率比我预期高。

如果你也是做快餐/小吃的店主，可以评论区扣 1
我发你完整的「餐饮小红书定位模板」。
```

## 笔记 3：干货笔记（长尾流量）

### 标题
> 餐饮老板做小红书前必看：这 3 个坑 90% 的人都踩过

### 正文（节选）
```
做了 2 个餐饮老板的案例后，发现大家踩的坑高度一致：

坑 1：上来就拍「老板出镜讲创业故事」
→ 真实情况：老板出镜前 3 秒掉粉率 60%+
→ 正确做法：第一篇先用厨房实拍/客户反馈做信任建立，老板出镜放第二篇

坑 2：每周只发 1 篇
→ 真实情况：小红书起号期算法要求每周 ≥ 3 篇，最好 5 篇
→ 正确做法：把每周内容分成 4 个固定栏目，素材复用

坑 3：自己拍的产品图很丑
→ 真实情况：手机随手拍的产品图点击率比精心设计的低 40%
→ 正确做法：用「自然光 + 桌面背景 + 近距离」三要素

完整模板评论区扣 1。
```
