**适用场景**：用户从闲鱼/小红书/备用渠道添加微信后的全套沟通话术  
**核心目标**：让用户进群 → 培育 → 转化为付费客户

## 五、群规话术（用于群公告）

```
【群规 · 餐饮老板自媒体交流圈】

1. 本群仅限餐饮老板/店长/运营负责人加入，谢绝纯广告党

3. 群内禁止直接发广告/二维码，一经发现秒踢
4. 欢迎分享自己店踩过的坑和爆款笔记
5. 群里禁止直接讨论本群服务定价（避免带节奏）
6. 进群修改备注格式：[店名]_[品类]_[城市]
```

## 六、关键话术合规点

| 话术 | 规避点 |
|---|---|
| 加微信 | 改用「进群」「围观」「加我」 |
| 代运营 | 改用「陪跑」「内容策划」「服务」 |
| 推广 | 改用「分享」「交流」 |
| 红包返现 | **禁止**（微信判定营销封号） |

> 话术被微信判定营销导致封号的风险：表现是消息发不出去或功能受限，需减少频繁群发、使用正常聊天语气（详见 群运营sop.md）。
