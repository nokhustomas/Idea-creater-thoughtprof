# 群运营 SOP（餐饮老板自媒体交流圈）

**群名**：餐饮老板自媒体交流圈  
**群规模目标**：30-50 人（首批 ≥5 人启动）  
**运营周期**：day13-day28（共 16 天）

---

## 一、建群 SOP（Day 13）

### Step 1：拉人进群（首批 ≥5 人）
- 来源：day9-12 通过闲鱼/小红书/备用渠道添加的微信用户
- 发送欢迎话术（见 私域话术.md 模板 A/B/C）
- 用户回复同意后逐一拉入群
- **门槛**：首批用户 ≥5 人再启动（避免冷启动死群）

### Step 2：群设置
```
群名：餐饮老板自媒体交流圈
群公告：群规（见 私域话术.md 第五节）
群主：运营者本人
群管理：1-2 名高互动用户（早期避免）
```

### Step 3：开群仪式
```
[群主] 各位老板好！我是 [昵称]

这个群是我帮 2 家快餐店做小红书陪跑的过程中组建的
每周三、周五、周日晚 8 点我会分享干货 + 案例拆解
群里禁止发广告，欢迎分享自己店踩过的坑

进群请修改备注格式：[店名]_[品类]_[城市]
例如：张姐黄焖鸡_黄焖鸡_北京朝阳

为了避免群内潜水，第 1 周我会发 3 次红包活跃气氛
```

## 二、每周软性推广安排（每周 3 次）

> 任务硬指标：每周安排 3 次软性推广服务（群内分享干货+案例展示）

3. 坑 3：自己拍的产品图很丑—— 自然光+桌面+近距离 3 要素
4. 真实案例：北京张姐黄焖鸡的起号数据

**软性推广**：
- 中间穿插「我整理了一份定位模板，需要的扣 1」

## 三、群活跃度监控

### 关键指标（每日记录到 数据记录表.md）

| 指标 | 计算方式 | 警戒线 |
|---|---|---|
| 群消息阅读率 | 已读人数 / 群人数 | < 30% 为死群 |
| 日发言人数 | 当日发言去重用户数 | < 3 人为低活跃 |
| 加群人数 | 当日新增群成员 | < 1 人/周为停止增长 |
| 私聊咨询数 | 因群内分享引来的私信 | < 1 人/周为转化停滞 |

### 死群激活方案
**触发条件**：群消息阅读率 < 30% 或连续 3 天无人发言

**激活 SOP**：
1. 立即发红包（金额 1-5 元，人数 5-10 个）
2. 发提问式内容：「@所有人 大家觉得做餐饮自媒体最难的是哪一步？A/B/C/D 选一个」
3. 单独 @ 未发言的核心用户（高意向名单），问 1 个具体问题
4. 若 24 小时仍无活跃 → 邀请新用户入群稀释沉默比例

## 四、风险控制

### 话术被微信判定营销导致封号
**表现**：消息发不出去/功能受限

**应对**：
1. 立即停止所有群发（≥24 小时）
2. 改用 1 对 1 私信，模仿正常聊天语气
3. 不发敏感词（代运营/推广/加微信）
4. 用表情包/图片替代纯文字营销
5. 必要时更换运营账号

### 群成员投诉/退群
**应对**：
1. 私聊了解原因
2. 若是嫌广告多 → 调整分享频次
3. 若是嫌不匹配 → 礼貌送别，建议退群

### 群内恶意竞争/挖客
**应对**：
1. 立即移除
2. 公告重申群规
3. 保留证据必要时投诉

## 五、群成员分级

### 高意向（每日记录）
- 标准：7 天内互动 ≥3 次 或主动私信/群内 @ 提问咨询（详见 高意向用户筛选标准.md）

### 中意向（每周回访）
- 标准：进群后浏览但偶尔点赞

### 低意向（自然流失）
- 标准：长期不发言但未退群

> 重点运营资源向高意向倾斜（详见 day21-28 付费转化推进）。
