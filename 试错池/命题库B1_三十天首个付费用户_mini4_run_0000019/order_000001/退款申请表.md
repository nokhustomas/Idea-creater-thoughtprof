## 四、退款金额计算

### 计算公式
```

```

| 15-25 天 | 最高 **20%** |

## 五、申请流程

1. **客户填写本表** → 微信发给运营者
2. **运营者 3 个工作日内审核**：
   - 验证服务天数
   - 验证累计阅读量
   - 计算实际退款金额
3. **审核通过** → 7 个工作日内退款至客户微信/支付宝
4. **审核不通过** → 微信说明理由，客户可申诉

## 六、不退款情形确认（任一勾选即不退款）

- [ ] 客户主动停止发布内容导致无数据
- [ ] 客户拒绝提供素材导致服务无法进行
- [ ] 客户未按周报建议调整内容导致效果不佳
- [ ] 客户私自转售服务内容
- [ ] 客户店铺出现重大经营异常（关店/被处罚）
- [ ] 服务天数 < 15 天
