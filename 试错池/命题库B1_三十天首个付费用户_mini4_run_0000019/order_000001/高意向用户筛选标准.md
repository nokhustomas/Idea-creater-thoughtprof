# 高意向用户筛选标准

**用途**：从 day13-20 私域用户中筛选高意向名单，day21-28 阶段逐一私信推付费服务  
**核心目标**：最大化转化效率，避免浪费精力在低意向用户身上

---

## 一、筛选总标准（满足任一即可）

> 任务硬指标：**7 天内互动 ≥3 次** 或 主动私信/群内 @ 提问咨询过的用户

| 维度 | 高意向信号 |
|---|---|
| **互动频率** | 7 天内发言 ≥3 次 |
| **互动深度** | 主动在群里提问、@ 我、点赞 + 评论 |
| **主动私信** | 7 天内主动私信过 1 次以上 |
| **群内 @** | 在群里 @ 我提问过 |
| **朋友圈互动** | 给朋友圈点赞 + 评论 ≥3 次 |
| **转发分享** | 转发过我的笔记/朋友圈 |
| **来源渠道** | 闲鱼/小红书主动咨询过的客户（默认高意向） |

---

## 二、详细分级

### S 级（必推，最优先）
**满足以下任一条件**：
1. 7 天内互动 ≥3 次
2. 主动私信问过价格/服务/合作
3. 群内 @ 我提过具体问题
4. 朋友圈评论里问过具体问题
5. 转发过我的笔记/朋友圈到自己的群

**对应行动**：day21-22 立即 1 对 1 私信推付费服务

### A 级（次优先）
**满足以下任一条件**：
1. 7 天内互动 1-2 次
2. 朋友圈点赞 ≥5 次但未评论
3. 群里潜水但 @ 群友讨论过相关话题
4. 备注格式已修改（说明重视）

**对应行动**：day23-25 通过群分享 + 朋友圈持续触达，等用户主动来问

### B 级（培育）
**满足以下任一条件**：
1. 仅进群未发言
2. 仅点赞未评论
3. 仅围观未互动

**对应行动**：day26-28 群内分享中点名提问，激活后转 S/A 级

### C 级（自然流失）
**满足以下任一条件**：
1. 进群后从未活跃
2. 已退群
3. 明确表示不需要

**对应行动**：不主动触达，保留联系方式即可

## 三、剔除标准（非目标客户）

即使满足高意向标准，以下情况也要剔除：

| 情形 | 说明 | 处理方式 |
|---|---|---|
| 非餐饮行业 | 自称是 KOL/营销号/培训机构 | 礼貌婉拒 |
| 已明确无需求 | 「我随便看看」「已经有代运营」 | 不再主动推 |
| 预算严重不匹配 | 「想找 100 元/月以下的」 | 转介绍给低价服务商 |
| 同行套资料 | 自称是竞品代运营来打听 | 礼貌拒绝 |
| 骚扰用户 | 言语不当/恶意骚扰 | 直接拉黑 |

## 五、day21-28 触达节奏

### 批次 1（day21）：S 级用户
- 数量：预计 5-10 人
- 触达方式：1 对 1 私信（话术见 私域话术.md 模板 A）
- 目标：50% 收到报价单

### 批次 2（day23）：A 级用户
- 数量：预计 10-15 人
- 触达方式：群内分享中点名 + 朋友圈持续触达
- 目标：30% 主动私信来问

### 批次 3（day25）：S+A 级跟进
- 触达方式：对未回复的 S 级再次私信，对 A 级群内互动激活
- 目标：20% 进一步追问

### 批次 4（day27）：限时优惠收口
- 触达方式：朋友圈 + 群公告强调「最后 1 个名额」
- 目标：5-10% 最终签约

## 六、7 天互动次数的数据来源说明

> 任务硬指标：7 天内互动 ≥3 次

### 互动次数定义
| 类型 | 计数 |
|---|---|
| 群内发言（去重） | 1 次/天/人 |
| 群内点赞（按天） | 1 次/天 |
| 群内 @ 我提问 | 1 次/次 |
| 主动私信 | 1 次/条 |
| 朋友圈点赞 | 1 次/条 |
| 朋友圈评论 | 1 次/条 |

### 互动次数限制
- **同一用户同一天 10 次点赞 = 1 次互动**（避免刷量）
- **跨 7 天累计**：从 day13 起每个用户计算 7 天滚动互动次数

## 七、误判高意向用户的兜底

> 任务硬指标：误判高意向用户导致浪费精力 → 需复核筛选条件准确性

### 兜底机制
1. **每日复核**：每晚 22:00 复核当天私信回复率
2. **若 S 级用户回复率 < 30%**：
   - 重新审视筛选标准
   - 增加「必须有具体问题问过」门槛
   - 剔除纯点赞型用户

3. **若 A 级用户激活率 < 10%**：
   - 调整触达话术（更直接）
   - 增加限时优惠元素

## 八、典型客户画像（基于实际数据归纳）

### S 级用户画像
- 进群后 24 小时内主动发言
- 至少问过 1 个具体问题（"怎么定价""能不能退款"）
- 朋友圈互动 ≥3 次
- 来源：闲鱼主动咨询（转化率最高）

### 转化率历史数据（基于 2 个免费案例的口头反馈）
- 闲鱼主动咨询 → 加微信 → 进群 → 签约：约 20-30%
- 小红书主动私信 → 加微信 → 进群 → 签约：约 15-25%
- 群内自然加入 → 签约：约 5-10%
