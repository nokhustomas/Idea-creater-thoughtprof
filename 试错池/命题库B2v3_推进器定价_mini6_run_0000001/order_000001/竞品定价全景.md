## 五、横向价格带速查表（AI想法推进对标）

| 类别 | 价格带（月/人或项目） | 交付物形态 |
|---|---|---|
| Devin 类 Agent | $20–$500/月 | 端到端自动编码（仍在 Beta） |
| AI 编程助手 | $0–$40/月 | 代码补全/对话 |
| 大模型 C 端 | $20–$60/月 | 对话/搜索 |
| 精品咨询 | $30k–$200k/项目 | 战略/路线图 |
| 四大/顶级咨询 | $50k–$2M/项目 | 全套战略与执行 |
| 国内本土咨询 | ¥30万–¥500万/项目 | 战略+组织 |

> **结论（截至训练数据）**：在"AI 想法推进 = 输入想法 → 深度查证 → 可执行路线图+交付物"这条赛道上，AI 工具端定价 **\$20–\$60/月**（太低、无法体现"深度查证"价值），咨询公司端定价 **¥30 万+/项目**（太高、对早期想法不友好）。中间存在 **¥2,000–¥40,000/项目** 的明显空白带，正是 AI 想法推进服务可切入的定价区间。
