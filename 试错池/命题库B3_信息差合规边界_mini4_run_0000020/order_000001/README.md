# 二手平台信息差生意合规边界研究

## 项目简介

本项目是"二手平台信息差生意全景研究"的合规调研交付物，重点研究国内主流二手交易平台（闲鱼、转转、拍拍、拼多多二手、多抓鱼）的数据获取合规边界，为单人月入5000的可行路径提供合规参考。

**核心原则**：拒绝灰产、严格区分法律强制与平台规则、标注信息时效性。

## 合规边界总结

1. **法律层面**（强制约束）：
   - 《数据安全法》《个人信息保护法》《刑法》第285条
   - 非法获取数据可能承担行政责任、刑事责任

2. **平台规则层面**（合同义务）：
   - 服务条款、用户协议、社区规范
   - 违反可能承担违约责任、账号封禁
   - **明确标注**：平台规则 ≠ 法律强制

3. **技术协议层面**（君子协定）：
   - robots.txt（IETF协议）
   - **明确标注**：仅约束自愿遵守的爬虫，不等同于法律禁止

## 拒绝灰产声明

本项目明确拒绝以下行为：
- 提供具体攻击性爬虫代码
- 教授绕过平台技术保护措施
- 协助批量爬取用户个人信息
- 任何违反《个人信息保护法》《数据安全法》的数据获取行为

**合规路径建议**：
- 通过官方API或商务合作获取数据
- 公开页面浏览需遵守robots.txt与服务条款
- 商业使用前咨询专业法律意见
