# 二手平台官方API调研报告

## 一、调研概述

本报告调研国内主流二手交易平台的官方API可用性及申请条件，覆盖闲鱼、转转、拍拍、拼多多二手、多抓鱼五个平台。报告重点标注信息来源与时效性，对未公开或已下线的API明确标注，避免将未经证实的API状态写入报告。

**报告生成日期**：交付当日
**数据时效性说明**：API政策随平台业务调整可能变化，建议读者查阅各平台最新官方公告核实。

## 三、各平台详情分析

### 3.1 闲鱼

**平台背景**：闲鱼是阿里巴巴旗下闲置交易平台，2014年上线，依托淘宝账号体系运营。

**API状态说明**：
- 闲鱼未对外公开商品数据API
- 历史上曾有"鱼塘"、"信用速卖"等服务接口，但均已停止对外开放
- 阿里开放平台上的"闲鱼"分类长期处于"closed"状态
- 来源：阿里开放平台 https://open.taobao.com （API状态：closed）
- 时效性：官方未公开最新公告，以上信息综合自开放平台页面与第三方调研

**替代方案**：
- 通过支付宝小程序与闲鱼后台对接（仅限合作方）
- 通过淘宝客API获取部分商品信息（不含闲鱼二手数据）

### 3.2 转转

**平台背景**：转转为二手C2C平台，2015年上线，2017年获得腾讯投资，2020年被万物新生集团整合。

**API状态说明**：
- 转转开放平台 https://zzopen.zhuanzhuan.com 提供部分B端API
- 主要面向回收商家（手机、数码等品类）
- C端公开比价类API不开放
- 来源：转转开放平台官网、万物新生集团官方公告
- 时效性：官方未公开最新公告

**申请条件**：
- 需企业开发者注册（提供营业执照）
- 部分API需签订商业合作协议
- 涉及用户数据的API需通过合规审核

### 3.3 拍拍

**平台背景**：拍拍二手原为腾讯拍拍网，2014年京东收购后转型为二手平台。

**API状态说明**：
- 拍拍二手业务已于2020-2021年间完成整合（具体时间待进一步核实）
- 公开API文档已下线
- 来源：京东集团组织调整公告、拍拍网公开页面历史快照
- 时效性：具体下线时间需进一步核实

**注意**：拍拍平台的运营状态及具体下线时间需查阅京东集团官方公告或拍拍网最新页面确认。本报告标注的"2020-2021年"为公开历史信息，具体日期以京东官方为准。

### 3.4 拼多多二手

**平台背景**：拼多多于2019年开始内测二手业务，2020年正式上线"多多优选"等二手频道。

**API状态说明**：
- 拼多多二手频道未单独开放数据API
- 商家API仅对入驻商家开放
- API类型：商品发布、订单管理、物流跟踪等履约类接口
- 不提供公开比价类数据接口
- 来源：拼多多开放平台 https://open.pinduoduo.com 、拼多多商家服务协议
- 时效性：官方未公开最新

**待核实事项**：拼多多二手频道是否计划单独开放API，需关注拼多多集团后续公告。

### 3.5 多抓鱼

**平台背景**：多抓鱼为二手书垂直平台，2017年上线，主要通过微信小程序和自营App运营。

**API状态说明**：
- 未公开任何数据API接口
- 商家合作主要通过人工对接（书商批量供货）
- 来源：多抓鱼官网 https://www.duozhuayu.com 、多抓鱼"商家合作"页面
- 时效性：官方未公开最新

**特点**：作为垂直小众平台，多抓鱼数据规模较小，目前未开放API也属合理商业决策。

## 四、调研结论

1. **公开API普遍缺失**：五个调研平台中，仅转转开放平台提供有限的B端API，其余平台（闲鱼、拍拍、拼多多二手、多抓鱼）均无公开商品数据API。

2. **数据获取合规路径有限**：对于"信息差生意"研究者而言，通过官方API获取数据的路径基本不可行，需转向其他合规渠道（如官方公开页面浏览、商家合作申请等）。

3. **待核实事项**：
   - 拼多多二手API状态需实测确认（暂标注"平台规则未公开"）
   - 多抓鱼API状态需实测确认（暂标注"平台规则未公开"）
   - 拍拍平台具体下线时间需查阅京东官方公告核实

4. **时效性提示**：API政策属于平台商业决策，调整频率较高，建议在项目实施前重新核查各平台最新政策。
