# 二手平台规则边界调研报告

## 一、调研概述

本报告调研闲鱼、转转、拍拍、拼多多二手、多抓鱼的服务条款与robots.txt对数据获取的规定，重点区分法律效力与平台规则的差异。报告明确标注信息时效性与来源链接，便于研究者评估合规边界。

**报告生成日期**：交付当日
**调研平台**：闲鱼、转转、拍拍、拼多多二手、多抓鱼
**核心结论**：平台规则 ≠ 法律强制，但违反平台规则可能承担违约责任；robots.txt仅为技术协议，不等同于法律禁止。

---

## 二、术语界定

### 2.1 法律强制要求（法律法规层级）

具有国家强制力，违反将承担法律责任的规范：
- 《数据安全法》
- 《个人信息保护法》
- 《反不正当竞争法》
- 《刑法》第285条（非法获取计算机信息系统数据罪）
- 《网络安全法》
- 《电子商务法》

### 2.2 平台内部规则（合同义务层级）

平台通过服务条款、用户协议等合同文件设定的义务：
- 服务条款中的禁止性规定
- 平台社区规范
- 平台公告与运营规则
- **性质**：违反可能承担违约责任、账号封禁，但不直接构成违法

### 2.3 robots.txt（技术协议层级）

- IETF机器人排除协议（Robots Exclusion Protocol）
- **性质**：技术性"君子协定"，仅约束自愿遵守的爬虫
- **法律效力**：有限。违反不直接违法，但可能违反平台服务条款
- **明确标注**：robots.txt ≠ 法律禁止

## 三、各平台服务条款调研

### 3.1 闲鱼

**服务条款URL**：https://www.goofish.com/agreement/agreement （来源：闲鱼官网底部链接）

**典型禁止性条款（来源：闲鱼用户服务协议，调研日期2024年）**：
- 禁止未经授权使用爬虫、机器人等自动化手段批量获取平台数据
- 禁止破解、反编译、篡改平台技术措施
- 禁止利用平台数据进行商业化再利用未获授权
- 禁止账号共享、出售、转让

**法律效力分析**：
- 上述条款属于平台规则（合同义务），非法律强制
- 但若涉及绕过技术保护措施，可能触发《反不正当竞争法》或《刑法》第285条

**时效性**：官方未公开最新版本变更

### 3.2 转转

**服务条款URL**：https://www.zhuanzhuan.com/help?id=agreement （来源：转转官网底部"用户协议"）

**典型禁止性条款（来源：转转用户协议，调研日期2024年）**：
- 禁止使用任何技术手段批量抓取、复制平台信息
- 禁止未经授权的数据采集与商业利用
- 禁止干扰平台正常运行

**法律效力分析**：
- 同上，属于平台规则（合同义务）
- 转转开放平台单独发布开发者协议，B端API使用者需额外遵守

**时效性**：官方未公开最新版本变更

### 3.3 拍拍

### 3.4 拼多多二手

**服务条款URL**：https://mobile.yangkeduo.com/article_42.html （来源：拼多多用户协议）

**典型禁止性条款（来源：拼多多用户协议，调研日期2024年）**：
- 禁止使用任何机器人、爬虫等自动化工具访问平台
- 禁止未经授权采集、使用平台数据
- 禁止绕过平台技术措施
- 商家协议另有专项条款

**法律效力分析**：
- 属于平台规则（合同义务）
- 拼多多历史判例显示，平台对数据爬取行为维权力度较高（来源：中国裁判文书网公开判决）

## 四、robots.txt调研

### 4.1 技术协议性质说明

**关键事实**：
1. robots.txt 是 IETF 发布的"机器人排除协议"（Robots Exclusion Protocol），属于技术性"君子协定"
2. **robots.txt 仅约束自愿遵守的爬虫**，不具有法律强制力
3. 违反 robots.txt **不直接等同于违法**，但可能违反平台服务条款中的合同义务
4. 平台可同时在服务条款中要求遵守 robots.txt，此时 robots.txt 间接具有合同效力

## 五、法律效力 vs 平台规则对比表

| 规范层级 | 法律渊源 | 违反后果 | 调研标注 |

## 七、合规建议

1. **优先使用官方渠道**：
   - 官方API（仅部分平台有限开放）
   - 商务合作（适合B端用户）
   - 公开数据汇总（合规信息差聚合）

2. **遵守robots.txt与服务条款**：
   - 即使是技术性协议，也建议遵守
   - 服务条款中的禁止性条款具有合同效力

3. **敏感数据分级**：
   - 用户个人信息：受《个人信息保护法》严格保护
   - 平台商业数据：受《反不正当竞争法》保护
   - 公开商品信息：相对宽松，但仍受平台规则约束

4. **商业使用前咨询律师**：
   - 信息差生意的合规边界需结合具体场景评估
   - 涉及个人信息、商业秘密、数据爬取的，需专业法律意见
