# 中介费对照：DIY 各步骤 vs 中介服务费区间

> 说明：本文列出美本申请全流程各步骤（选校、文书、标化送分、申请费、面试、签证、行前）的 DIY 成本 vs 中介公开报价区间。所有数据**截至训练数据，需核**，因为中介报价随市场/机构/年份波动大。

---

## 1. DIY 申请全流程步骤拆解

| 步骤 | 说明 | DIY 自费 | 中介服务（含） |
|---|---|---|---|
| **Step 1** | 选校（CDS + 官网调研） | 免费 | 3000–8000 美元 |
| **Step 2** | 文书（主文书 + 补充文书） | 0–500 美元（资料费） | 1500–5000 美元/8–10 篇 |
| **Step 3** | 标化考试（SAT/TOEFL） | 60+245 美元/次 | 含在全程服务包 |
| **Step 4** | 成绩送分（SAT/TOEFL） | 12+20 美元/校 | 含在全程服务包 |
| **Step 5** | 申请费（Common App + 各校） | 80+30 美元/校 | 含在全程服务包 |
| **Step 6** | 面试（校友面试辅导） | 免费（校友自主联系） | 500–2000 美元/次 |
| **Step 7** | 签证（F-1 签证辅导） | 185 美元 + 0 自学 | 1000–3000 美元 |
| **Step 8** | 行前（住宿/选课/接机咨询） | 免费 | 500–2000 美元 |

### 2.7 总 DIY 自费估算（10 所申请为例）

```
SAT 报名: 60 美元（1 次）× 3 次 = 180 美元
SAT 送分: 免费 4 所 + 12 × 6 所 = 72 美元
托福报名: 245 美元 × 2 次 = 490 美元
托福送分: 免费 1 所 + 20 × 9 所 = 180 美元
AP: 94 × 5 门 = 470 美元（11 年级考）
Common App: 80 × 10 所 = 800 美元（含附加费）
签证: 350 + 185 = 535 美元
小计: 180 + 72 + 490 + 180 + 470 + 800 + 535 = 2,727 美元

约合人民币 2 万元 RMB（按 7.3 汇率，需核）
```

## 5. 省钱替代方案（DIY 资源清单，截至训练数据，需核）

| 中介服务 | DIY 替代 | 效果对比（待验证） |
|---|---|---|
| **文书修改** | 校内英语老师 / 升学办 / 学长学姐 / ChatGPT 辅助改写 / Hemingway Editor | AI 辅助效果**待验证**；真人反馈更可靠 |
| **选校咨询** | Common Data Set 自学 / College Board Big Future / 学校 Counselor | 效果等同于中级顾问 |
| **面试辅导** | 看 YouTube 大学面试范例 + 校友网络 | 效果需 ≥ 3 次模拟面试 |
| **签证辅导** | 美国大使馆官网 + YouTube 面签范例 + 知乎经验帖 | 效果等同于基础签证辅导 |
| **标化培训** | Khan Academy（SAT）+ ETS 免费资源（TOEFL） | 效果等同 70–80% 付费课程 |
| **背景提升** | 学校社团 + 公开竞赛（AMC/USACO/CTB） | 含金量看成绩，DIY 不输 |
| **夏校申请** | 学校 Counselor 推荐 + Summer Program 官网直申 | 选公立项目可省 2–5 万 |

> ⚠️ **省钱方案效果存争议**：AI 辅助文书质量有差异；真人反馈仍是黄金标准。**效果待验证**。

## 7. 中介避坑指南（截至训练数据，需核）

- ❌ **承诺"保录 TOP 10"**：绝对不合法，是销售话术；正规中介不会承诺。
- ❌ **低价 1 万元全包**：多为模板文书 + 大量学生流水线作业。
- ❌ **顾问资质不透明**：查顾问背景（是否前招生官 vs 普通销售）。
- ❌ **隐形消费**：除套餐价外还收"加校费"、"加文书费"、"加面试费"。
- ❌ **不签合同或合同不含退款**：必须书面合同 + 退款条款。
- ❌ **顾问频繁离职**：中介流动性大，承诺的顾问可能中途换人。

## 8. DIY vs 中介决策树（截至训练数据，需核）

```
1. 你的标化（GPA + SAT + TOEFL）能稳定在 Top 30 中位数以上？
   ├─ 是 → 全 DIY 没问题
   └─ 否 → 考虑局部中介（仅文书/选校）

2. 你的时间（每天 2 小时+）能投入 18 个月？
   ├─ 是 → 全 DIY 没问题
   └─ 否 → 考虑半 DIY（部分外包）

3. 你的家庭能否负担 5 万 RMB 中介费不影响留学预算？
   ├─ 是 → 局部中介可以考虑
   └─ 否 → 全 DIY + 校内免费资源
```
