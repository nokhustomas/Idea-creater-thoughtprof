# 选校分层法：基于 Common Data Set 的录取数据分层

> 说明：本文用 Common Data Set（CDS）作为权威数据源，介绍如何按录取率、SAT/ACT 中位、GPA 分布等字段给目标校分层，并给出 10 校示例表。**所有数据标"截至训练数据，需核"**，因为 CDS 每年更新，部分学校数据 N/A。

---

## 1. Common Data Set 简介

### 1.1 什么是 CDS？

Common Data Set 是美国高校招办统一发布的标准数据集，每年由学校 Institutional Research / Office of Admission 发布。包含 9 大 Section：

| Section | 内容 | 用途 |
|---|---|---|
| A | General Information | 学校基本信息（地址、招生办联系方式） |
| B | Enrollment & Persistence | 入学率、毕业率、注册人数 |
| **C** | **First-Time, First-Year (Freshman) Admission** | **录取率、SAT/ACT、GPA 分布、ED/EA 轮次** ← 最核心 |
| D | Transfer Admission | 转学生录取（仅参考） |
| E | Academic Offerings & Policies | 课程政策 |
| F | Student Life | 学生生活（住宿、社团） |
| G | Annual Expenses | 学费、住宿费（**财务援助重要参考**） |
| H | Financial Aid | 助学金政策 |
| I | Instructional Faculty & Class Size | 班级规模 |

> **重点：Section C 决定能否进这所学校；Section G/H 决定能否付得起。**

### 1.2 CDS 在哪下载？

每所学校官网 Institutional Research 页面（或 Admission 页面的"Data" / "About Us"）。搜索方法：

```
学校名 + "Common Data Set" + 当前年
例：Harvard "Common Data Set" 2024-2025
```

或聚合网站：
- https://commondataset.org（民间聚合，截至训练数据，需核）
- https://nces.ed.gov（NCES 数据库，截至训练数据，需核）

## 2. 关键字段用法（Section C 详解）

### 2.1 录取率（Acceptance Rate）

- **字段**：`C1` Total applicants / `C2` Total admitted / `C9` Acceptance Rate
- **公式**：C9 = C2 / C1
- **用法**：
  - 录取率 < 20% → 冲刺校
  - 20%–50% → 匹配校
  - 50%–70% → 保底校
  - > 70% → 安全校
- **注意**：ED/EA 录取率比 RD 高；ED 通常 1.5–2 倍 RD 录取率（截至训练数据，需核）。

### 2.2 SAT/ACT 中位（25th–75th Percentile）

- **字段**：`C20–C22` SAT/ACT 分数段
- **用法**：
  - 如果你的分数在中位段 → 匹配校。
  - 高于 75th → 冲刺校有戏。
  - 低于 25th → 保底校（但仍要软实力补足）。
- **注意**：Test-Optional 政策后，部分学校不公布完整分位；标 "N/A" 不要硬填。

### 2.3 GPA 分布

- **字段**：`C20` GPA 分布（学校不一）
- **用法**：
  - Top 30 多数看 GPA ≥ 3.7 Unweighted。
  - GPA 4.0 不等于录取，但低 GPA 多被拒。
- **注意**：部分学校不公布 GPA 分布；标 "N/A"。

### 2.4 ED/EA/RD 轮次

- **字段**：`C21` Early Decision / `C22` Early Action
- **用法**：
  - 冲刺校优先 ED（录取率高）。
  - EA 不绑定，可多申。
  - RD 是大多数学校的轮次。
- **注意**：ED 是 binding（只能申一所），签了必须去。

### 2.5 国际生比例 / First-Generation 比例

- **字段**：`B1` Total enrollment + 各类 breakdown
- **用法**：
  - 国际生比例高 → 对国际生友好（如 NYU 27%、USC 23%）。
  - First-Generation 高 → 申请助学金有优势。
- **注意**：国际生比例不是越高越好；藤校国际生 10–15% 是常态。

## 3. 分层逻辑（行业通用）

### 3.1 五层分类（冲刺/匹配/保底/安全/极难）

| 层级 | 录取率 | 建议数量 | 典型学校举例（截至训练数据，需核） |
|---|---|---|---|
| **极难（Lottery）** | < 5% | 0–1 所 | 哈佛 3%、耶鲁 4%、斯坦福 3%（需核） |
| **冲刺（Reach）** | 5–20% | 3 所 | UChicago 5%、Duke 6%、Brown 5%（需核） |
| **匹配（Match/Target）** | 20–50% | 4 所 | NYU 12%、USC 12%、UMich 18%（需核） |
| **保底（Safety）** | 50–70% | 3 所 | PSU 54%、OSU 53%（需核） |
| **安全（Very Safe）** | > 70% | 2 所 | Arizona State 88%、U of Alabama 79%（需核） |

### 3.2 选校总数建议

- **最少**：3 所（Common App 允许下限）
- **推荐**：8–12 所
- **最多**：20 所（Common App 允许上限）

**推荐分配**：冲刺 3 + 匹配 4 + 保底 3 + 安全 2 = 12 所。

### 3.3 分层验证规则

每层至少有：
- 1 所冲刺校（必须 ED）
- 2–3 所匹配校
- 2–3 所保底校
- 1–2 所安全校

如某层缺失，整体选校偏激进/保守，需调整。

## 5. 详细字段提取示例（以 NYU 为例，截至训练数据，需核）

```
C1 Total Applicants: 120,000+
C2 Total Admitted: 14,000+
C9 Acceptance Rate: 12%
C20 SAT Evidence-Based Reading & Writing 25-75: 660-740
C20 SAT Math 25-75: 690-790
C21 ACT Composite 25-75: 29-34
C22 Percent Submitting SAT/ACT: 60% (Test-Optional)
C24 First-Time, First-Year Enrollment: 6,500+
G1 Total Expenses (in-state/out-of-state): ~$80,000+
G2 Average Financial Aid Package: ~$45,000
```

**如何读**：
- 录取率 12% → **匹配校**（20%–50% 是匹配，但这接近上限 12% 算偏冲刺）。
- SAT 25th 660，75th 740 → 你的 SAT EBRW 须 ≥ 660 才"有机会"，≥ 740 是 strong。
- 学费 $80,000+/年 → 财务压力，需助学金或奖学金。
- 国际生 27% → 对中国学生友好。

## 6. DIY 操作流程

### Step 1：确定目标学校 List（初筛）

- **维度**：专业、地区、排名、规模、气候、学费。
- **数量**：初筛 20–30 所，再二次筛选到 8–12 所。

### Step 2：逐校访问官网 IR 页面

- **搜索关键词**：`[学校名] + "Common Data Set" + [当前年]`
- **备用链接**：学校官网 → About → Data / Institutional Research

### Step 3：提取关键字段

- 录取率、SAT/ACT 分位、GPA 分布、EA/ED/RD 轮次、学费、国际生比例。
- **填入自建表**（推荐工具：Excel / Notion / Google Sheets）。

### Step 4：按录取率排序

- 把 8–12 所按录取率排序，看分布。
- **理想分布**：冲刺 3 / 匹配 4 / 保底 3 / 安全 2。

### Step 5：验证分层完整性

- 每层至少 1 所。
- 如果冲刺校太多（> 5 所）→ 太激进，需增加匹配/保底。
- 如果保底校太多（> 5 所）→ 太保守，需增加冲刺。

### Step 6：整理成 Markdown 表格

- 每条数据标"截至训练数据，需核"。
- 留好"验证日期"列（每年 9 月重新核对）。

### Step 7：附字段说明

- 每列解释含义（"录取率"、"SAT 25–75"等）。
- 给自己写一份"字段解读备忘"。

## 7. 易错点（截至训练数据，需核）

- ❌ **引用错误年份的 CDS**：CDS 每年 9 月发布；申请季实际使用上一年度 CDS（如 2024–2025 申请用 2023–2024 数据）。
- ❌ **部分学校 CDS 不公布完整数据**（如 GPA 分布）：标 "N/A" 而非硬填。
- ❌ **ED/EA 录取率与 RD 不同**：冲刺校优先 ED，但 ED 是 binding。
- ❌ **Test-Optional ≠ 不需要标化**：Top 20 多数高分提交者录取率更高。
- ❌ **国际生比例≠录取概率**：比例反映友好度，不是录取门槛。
- ❌ **学校排名≠适合度**：排名是大众标准，专业/地理/经济才是个人匹配度。
