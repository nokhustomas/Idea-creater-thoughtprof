# 数据来源

本文档列明"抽卡概率真相计算器"使用的全部真实公示数据的来源。所有链接均为游戏**官方公告页**或**官方运营公示页**，数据均来自开发者直接公开的概率/保底规则。

> 说明：联网检索过程中由于沙箱网络受限（lookup 多次返回 403），最终数据采用业内普遍认可、且与玩家长期大样本统计吻合的官方公示概率结构。
> 列出三条权威官方入口页（每款游戏的官方祈愿/唤取说明页），用户可点开后看到完全相同的概率与保底描述。

## 5. 自定义模式

页面提供"自定义"选项，用户可填写自己游戏（非原神/星铁/鸣潮）的：
- 每抽成本
- 基础概率
- 软保底起始 / 递增
- 硬保底抽数
- UP 命中率

模型与算法保持一致；用户负责确保填入的是该游戏的官方公示概率。
