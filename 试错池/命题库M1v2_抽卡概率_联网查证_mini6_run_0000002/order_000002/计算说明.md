# 计算说明

本文档解释「抽卡概率真相计算器」的数学推导与算法实现，使任何拥有公示概率/保底规则的人可以**手算复算**并验证。

## 1. 模型假设

记抽到目标角色（5★/UP）所需的总抽数为随机变量 X。模型假设每一抽的瞬时 5★ 概率仅与"该次是第几抽"有关，与历史无关（无记忆模型）。

设：
- `base_rate` —— 基础 5★ 概率（即"平时"单抽出货概率）
- `soft_pity_start` —— 软保底起始抽数（从这一抽之后，每抽概率递增）
- `soft_pity_increment` —— 软保底每抽增加的固定概率
- `hard_pity` —— 硬保底抽数（在第 N 抽时必定出货，即该抽概率 = 1.0）
- `featured_rate` —— UP 命中率（命定值，如 50/50 = 0.5）

## 2. 每一抽的瞬时概率

构造长度为 `hard_pity` 的概率数组 `p[1..N]`：

```
对 i = 1 .. N:
  若 i < soft_pity_start:           p[i] = base_rate
  若 soft_pity_start ≤ i < N:        p[i] = base_rate + soft_pity_increment × (i - soft_pity_start + 1)
  若 i = N (硬保底):                  p[i] = 1.0
```

注意递增从 `soft_pity_start + 1` 那一抽开始加 1 个 inc，从 `soft_pity_start` 那一抽概率仍为 `base_rate`。这是绝大多数二次元抽卡手游（包括原神、星铁、鸣潮）的公示描述对应的标准实现。

> 验证：原神 / 星铁公示"74 抽开始进入软保底"，意味着第 73 抽仍为 0.6%，第 74 抽及之后每抽 +6%。同理鸣潮"65 抽开始软保底"，第 65 抽仍 0.8%，第 66 抽开始 +6%。

## 3. 期望抽数（5★）

```
存活到第 i 抽的概率:
  survival[i] = Π_{j=1..i-1} (1 - p[j])         (survival[1] = 1)
第 i 抽首次出货的概率:
  P(X = i) = survival[i] × p[i]
期望:
  E[X] = Σ_{i=1..N} i × P(X = i)
```

## 4. 期望抽数（含 UP / 大保底循环）

很多游戏（如原神）有「命定值」机制：第一次抽到 5★ 时只有 50% 概率是当期 UP，歪了则下一轮 5★ 必出 UP。

设每次抽到 5★ 时为 UP 的概率为 `f = featured_rate`，则独立重复直到第一次"出 UP"所需的 5★ 次数 Y 服从几何分布：

```
E[Y] = 1 / f
```

每获得一次 5★（不论 UP/歪）都需要 `E[X]` 抽，因此：

```
E[抽到 UP 所需的抽数] = E[X] / featured_rate
```

## 5. 期望花费

```
期望花费 = E[UP 抽数] × cost_per_pull
```

## 6. 90 分位数（最倒霉 10%）

定义：90 分位数 p90 是满足 P(X ≤ p90) ≥ 0.9 的最小抽数，即 90% 的玩家在 p90 抽以内出货；剩下 10% 的"非酋"要花更多。

计算方法：累积分布 P(X ≤ n) 随 n 单调递增，找到第一个 ≥ 0.9 的 n 即可。

## 7. 分布曲线

横轴 n = 1..N，纵轴 P(X = n)（柱状）或 P(X ≤ n)（累积）。前端有陡起的 0.6% 平段，再以约 6% 每抽斜率线性爬升，最后在 N 抽以 1.0 概率兜底。

## 8. 手算复算示例（原神）

设：
- base = 0.006, soft = 74, inc = 0.06, hard = 90, f = 0.5, cost = 160

第 74 抽概率 = 0.6%；第 75 抽概率 = 6.6%；……；第 89 抽概率 = 6 + 0.6 + 14×0.06 = 0.984；第 90 抽概率 = 1.0。

由自检脚本输出：
```
期望 5★ 抽数  : 62.9235
期望 UP 抽数  : 125.8471   (= 62.9235 / 0.5)
期望 UP 花费  : 20,135.5 原石
90 分位数     : 81 抽
```

→ 业界长期统计的"约 62.5 抽出货"与计算值 62.92 抽误差 < 1%，验证一致。

## 9. 自检项

selfcheck.py 会对三款游戏分别进行：
1. 期望 5★ 抽数与玩家社区长期统计交叉对比（容差 ±15%）
2. 硬保底机制（最后一抽前累计未出概率 < 1e-4）
3. 90 分位数输出
4. 概率归一性 Σ P(X=n) = 1

全部通过 → 退出码 0。
