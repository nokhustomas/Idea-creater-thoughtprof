        📚 数学原理说明
        
1. 单抽概率模型
   每抽 5★ 的瞬时概率为 p_n：
     - n < soft_pity_start：p_n = base_rate
     - soft_pity_start ≤ n < hard_pity：
         p_n = base_rate + soft_pity_increment × (n - soft_pity_start + 1)
     - n = hard_pity：p_n = 1.0  （硬保底必出）

2. 期望抽数
   E[X] = Σ_{n=1..H}  n · P(X = n)
   其中 P(X = n) = (1 - p_1)(1 - p_2)…(1 - p_{n-1}) · p_n

3. UP 期望（50/50 + 大保底循环）
   每获得一个 5★ 时，命定（UP）概率 = featured_rate。
   期望轮数 = 1 / featured_rate。
   E[X_UP] = E[X_5★] / featured_rate。

4. 花费
   cost = E[X_UP] × cost_per_pull

5. 90 分位数
   找最小 k，使 P(X ≤ k) ≥ 0.9。
   表示 90% 的玩家在 k 抽以内能拿到 UP，
   剩下 10% 的"最倒霉"玩家要花到第 k+1 抽甚至更多。
