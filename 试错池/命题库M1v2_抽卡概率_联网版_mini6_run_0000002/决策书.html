概率模型类型如何确定

模型决定计算器能支持哪些保底机制，题目要求通用性，需覆盖全部常见模型

多模型全支持（mind_first_principles）

为什么产出它：第一性原理要求从根本需求出发，题目要求"输入任意游戏公示的概率与保底规则"，需兼容所有类型

优点
  • 覆盖独立概率、软保底、硬保底、累进概率全部类型
  • 满足题目通用性要求，可计算任意游戏
缺点
  • 实现复杂度高，需实现4种不同算法
  • 软保底概率递增曲线参数需精确获取
  • 部分游戏规则可能混合多种机制

因果链：题目要求通用→需支持全部模型→从info_000006获取模型定义→各模型算法实现(info_000001)

关键信息：
  • info_000006:游戏概率模型包括独立概率、软保底(66抽5.8%递增至80抽100%)、硬保底(90抽必出)、累进概率
  • info_000001:输入任意游戏公示的抽卡概率与保底规则

核心模型优先（mind_mece）

为什么产出它：MECE要求不遗漏不重复，三款游戏案例已覆盖软硬保底，可先实现主流机制

优点
  • 实现难度降低，聚焦核心场景
  • 三款游戏案例已能覆盖软硬保底需求
缺点
  • 扩展性受限，其他游戏规则可能不支持
  • 不满足"任意游戏"的通用性要求

因果链：三款游戏案例需求明确→核心需求是原神鸣潮星铁→优先实现这3款的机制(info_000008)→后续扩展

关键信息：
  • info_000008:三款游戏已覆盖软保底(原神74抽起/鸣潮70抽起)和硬保底(原神90/鸣潮80/星铁90)
怎么选：如果需要计算任意游戏规则选多模型全支持；如果仅针对已知三款游戏做展示可先选核心模型优先

游戏案例选哪款

题目明确要求2-3款真实热门游戏，需选数据公开且机制有代表性的

原神+鸣潮+崩坏星穹铁道（mind_resource）

为什么产出它：题目明确要求热门游戏，这三款国内热度最高且数据相对公开

优点
  • 原神：软保底+硬保底+大小保底机制最复杂，典型
  • 鸣潮：软保底参数与原神不同，可对比
  • 星铁：保底继承机制独特，可展示继承逻辑
缺点
  • 部分数据存争议(如软保底具体参数)
  • 鸣潮数据相对少，需更多验证

因果链：题目要求2-3款真实热门游戏→三款热度最高→获取各游戏规则(info_000008)→计算验证

关键信息：
  • info_000008:原神5星1.6%/硬90/软74抽起+6%/大小保底；鸣潮5星1.807%/硬80/软70抽起+9.02%；[无来源]星铁5星硬保底90/4星9抽必出
  • info_000010:星铁保底可继承，最多180发必出UP

仅选原神（mind_constraint）

为什么产出它：约束思维下，数据最完整、机制最典型，可集中资源做精

优点
  • 数据最完善，社区研究最深
  • 机制最具代表性(软硬保底+大小保底)
  • 计算验证更容易
缺点
  • 覆盖场景单一
  • 不满足题目2-3款要求

因果链：数据完整度优先→原神数据最全→集中资源做深→后续扩展(info_000001)

关键信息：
  • info_000011:原神小保底90抽50%出UP，大保底180抽100%出UP
  • info_000012:原神保底可继承，同类型卡池永久继承
怎么选：如果需展示多种保底机制对比选三款；如果资源有限且追求精度可先选原神

数据来源如何确保可信

题目要求联网查证、过程可验证，数字需能复算，必须从官方或可靠渠道获取

lookup查官方公告（mind_constraint）

为什么产出它：题目明确要求"lookup查官方公告并带网址"，不符合则交付不合规

优点
  • 符合题目硬性要求，可带网址溯源
  • 官方数据最具权威性
缺点
  • 部分游戏官方数据不完整或未公示
  • 部分规则(如软保底)官方不公开承认

因果链：题目要求lookup查官方→搜索官方公告/概率公示页面→标注网址(info_000003)→数学过程可展开复算

关键信息：
  • info_000003:必须lookup查官方公告并带网址，不许写爬虫脚本
  • info_000005:数字要能复算，交付要真能用

社区汇总数据（mind_resource）

为什么产出它：社区已汇总大量实测数据，可快速获取

优点
  • 数据丰富，社区研究深入
  • 部分官方不公开的参数有实测参考
缺点
  • 非官方来源，权威性不足
  • 部分数据存争议
  • 可能不符合题目"查官方"要求

因果链：社区数据丰富→可快速获取→但需标注来源→可能需二次验证(info_000015)

关键信息：
  • info_000015:热门游戏详细概率及保底规则来自搜索结果，部分非官方
  • info_000010:星铁保底继承来源TapTap/九游非官方
怎么选：如果必须严格符合题目"查官方"要求选lookup查官方公告；如果允许参考社区数据可选社区汇总数据
