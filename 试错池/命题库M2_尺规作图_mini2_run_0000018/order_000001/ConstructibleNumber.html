Constructible Number

A real number a is a constructible number if and only if, starting with the rational numbers ℚ and a unit segment, it can be constructed using only the operations of addition, subtraction, multiplication, division, and square roots.

Equivalent Algebraic Characterisation

A number is constructible if and only if it lies in a field extension of ℚ whose degree is a power of 2. Equivalently, its minimal polynomial over ℚ has degree 2k for some non-negative integer k.

Historical Notes

  • Classical Greek construction problems (squaring the circle, trisecting the angle, duplicating the cube) remained unsolved for over 2000 years.
  • C. F. Gauss, in Disquisitiones Arithmeticae (1801), Section VII, gave the algebraic characterisation in terms of quadratic extensions.
  • P. M. Wantzel (1837) completed the criterion: a regular n-gon is constructible if and only if φ(n) is a power of 2.

Application to Regular Polygons

A regular n-gon can be constructed with ruler and compass if and only if cos(2π/n) is a constructible number. By the theorem above, this is equivalent to φ(n) being a power of 2.
