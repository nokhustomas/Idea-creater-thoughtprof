Trigonometry Constants

Common numerical values and exact algebraic expressions for trigonometric constants appearing in regular-polygon constructions.

cos(36°)

Exact form:

cos(36°) = (√5 + 1) / 4

Numerically:

cos(36°) ≈ 0.8090169943749474...

Minimal polynomial over ℚ:

4x² − 2x − 1 = 0

The two roots of this quadratic are (1 ± √5)/4, giving the constructive segment length for the regular pentagon.

cos(72°)

Exact form:

cos(72°) = (√5 − 1) / 4

Numerically:

cos(72°) ≈ 0.3090169943749474...

cos(2π/7)

No simple radical-of-radicals expression using only square roots exists. Numerically:

cos(2π/7) ≈ 0.6234898018587336...

The minimal polynomial of cos(2π/7) over ℚ is:

x³ + x² − 2x − 1 = 0

The three real roots of this cubic are cos(2π/7), cos(4π/7), cos(6π/7). Because the minimal polynomial has degree 3 (not a power of 2), cos(2π/7) is not a constructible number — therefore the regular heptagon is not constructible with ruler and compass.
