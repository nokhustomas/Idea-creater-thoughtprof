尺规作图的可与不可

为什么正五边形能用尺规作出，而正七边形永远不能？

面向高中生的交互式课件 · 基于 SVG 矢量画布 · 参考《普通高中数学课程标准（2017 年版 2020 年修订）》

一、引子：两个看似相似的问题

正五边形与正七边形看起来很像——都是把一个圆等分成若干份。奇怪的是，尺规作图（只用无刻度直尺与圆规）允许我们把圆等分成五份，却永远无法等分成七份。

这一节课，我们就用一段约 45 秒的自动演示先做一次正五边形，再花约 30 秒演示对正七边形的尝试与失败，然后从"可构造数"和"域扩张"的角度解释背后原因。

你也可以选择工具，自己在画布上拖动直尺和圆规，亲手试一试。

二、作图画布（SVG）

SVG 是 W3C 标准的矢量图形格式，每一个 <circle>、<line> 本身就是数学对象（圆心+半径、两点确定直线），与几何代数化思路天然契合，可以直接挂 DOM 事件。下面就是这节课的主画布。

当前工具：直尺

操作提示：

· 直尺：依次点击两个已有点画直线；

三、可构造数：尺规作图的"语言"

尺规作图允许的操作只有三类：

  1. 过两个已知点画直线；
  2. 以一个已知点为圆心、过另一个已知点画圆；
  3. 取两条直线 / 两圆 / 直线与圆的交点。

如果我们一开始就有"单位长度 1"，那么经过有限步上述操作能够得到的所有长度，就叫可构造数（Constructible Number）。从代数角度看，它们恰好是：通过对 1 做有限次加、减、乘、除、开平方所得到的全部实数。

高斯在《Disquisitiones Arithmeticae》（《算术研究》）Section VII 中给出关键定理：每一步尺规作图（作直线 / 圆 / 取交点）对应的数域扩张次数不超过 2。因此，一个数可构造，当且仅当它所满足的极小多项式次数是 2 的幂。

正 n 边形能尺规作图的充要条件是 cos(2π/n) 是可构造数。这就把"画图问题"转化成了"代数问题"。

四、正五边形案例：能作

步骤顺序（任选一弦作起手）：

  1. 任选两点 A, B 作弦 AB；
  2. 作 AB 的中垂线得圆心 O；
  3. 以 O 为圆心、OA 为半径画圆；
  4. 在圆上依次截取五等分点；
  5. 顺次连接五点即得正五边形。

关键在 cos(36°)。由五等分圆的几何关系可以推出

cos(36°) = (√5 + 1)/4 ≈ 0.809016

代入可得 4 cos²(36°) − 2 cos(36°) − 1 = 0，即 4x² − 2x − 1 = 0 正是 cos(36°) 的极小多项式，次数为 2 = 2¹，是 2 的幂。因此 cos(36°) 可构造 → 正五边形可尺规作图。

数值复算：(√5 + 1) / 4 = (2.2360679... + 1) / 4 ≈ 0.80901699... ✓ 与计算器一致

五、正七边形案例：永远不能

用类似思路考虑 cos(2π/7)。数值上

cos(2π/7) ≈ 0.6234898...

它也是代数数，但满足一个三次方程

x³ + x² − 2x − 1 = 0

这是它在 ℚ 上的最小多项式，次数为 3。但 3 不是 2 的幂（因为 3 = 2log₂3 ≈ 21.585，不是 2 的整数次幂），所以 cos(2π/7) 不是可构造数，正七边形因此永远不能尺规作图。

数值复算：cos(2π/7) = cos(0.8975979...) ≈ 0.6234898... ✓

这不是"还没找到办法"，而是"原则上不可能"。1593 年 Viète（韦达）曾专门研究过正七边形作图，最终只能给出近似解。1801 年 Gauss 在《算术研究》中给出了完整的可构造数理论，再后来 Galois 理论从根式可解的角度彻底证明了这条边界。

六、动手试一试

  1. 点"演示：正五边形"观看自动作图（约 45 秒），注意每步标号；
  2. 点"演示：正七边形尝试"观看为什么无论怎么选交点都凑不出七等分；
  3. 选"圆规"，单击画布定圆心，再单击另一处定半径画圆；
  4. 选"直尺"，点击两个已有点画直线；
  5. 遇到多交点时，系统弹出菜单让你选哪一个；
  6. 按 Ctrl+Z 撤销，按 空格 推进动画下一步。

所有交点都由 math.js 中的解析几何算法算出：直线与圆用判别式 Δ，圆与圆先化为直线再求交。
