ℹ️ 使用说明

本工具基于下列公式对比两种策略的终值差异：

  • 等额本息：M = P · r · (1+r)^n / ((1+r)^n - 1)
  • 等额本金：每月本金 = P / n，每月利息 = 剩余本金 × r
  • 理财月复利：F = P · (1 + i)^n，其中 i = 年化/12
  • 实际购买力：将每期现金流按通胀率折现至今日现值

决策规则：

  • 若实际净收益 > 0：推荐 提前还款（PREPAY）
  • 若实际净收益 ≤ 0：推荐 投资理财（INVEST）

局限性：理财收益与通胀为预测值；银行政策以当地支行为准；本工具不构成投资建议。
