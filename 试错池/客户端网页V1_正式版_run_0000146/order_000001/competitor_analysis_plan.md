# 竞品分析方案（Competitor Analysis Plan）

> 归属：想法推进器（Idea-Pusher）客户用网页系统
> 目的：在「一句话开局 → 自动出成品」这条赛道上，把同行玩家逐个摊开，找差异化。

## 1. 目标

1. 列出 6–10 个最相关的竞品（待核实名单）。
2. 用统一维度打分，输出一张可比表。
3. 找到 3 个 Idea-Pusher 可以放大、3 个必须避开的弱点。
4. 把结论回流到 `PRICING` 与 `INDEX_HTML` 文案。

## 3. 实施步骤

| 阶段 | 时长 | 产出 |
|------|------|------|
| 确认竞品清单 | T+0 | 本表 1.0 |

| 按维度打分 | T+7 | `competitor_analysis_criteria.md` |
| 交叉讨论 + 结论 | T+10 | 本文件末尾「结论」 |

## 4. 数据来源

- 官方网站与定价页（手工截图 + 关键文本摘录）。
- 第三方评测（待核实清单）。
- 真实试用：每个竞品免费档提交一句话，看会得到什么。

## 5. 分析维度（与 criteria.md 对齐）

- 入门门槛（是否需要注册 / 学习）
- 一句话到成品的端到端时延
- 成品是否可下载、可改
- 定价与免费档
- 中文支持与排版
- 透明度（是否能看进度 / 看过程文件）
- 可审计性（是否有日志、归档）
- 团队协作能力
- API 与二次开发

## 6. 评分规则

- 每个维度 1–5 分，1=很差，5=很强。
- 取两位评估人独立打分后取平均；差异 >2 分时复议。
- 维度权重见 `competitor_analysis_criteria.md`。

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 主观偏见 | 双人独立打分 + 引入外部盲审一次 |
| 数据过期 | 半年回归一次 |
| 只能试用免费档 | 至少两人分别付费一次取证据 |
| 中文支持评估带情绪 | 用同一段中文 prompt 实测，记录产出 |
