# 迭代优化过程记录（Iteration Log）

> 归属：想法推进器（Idea-Pusher）客户用网页系统
> 用途：每改一处，按一条记录写在本文件，附触发反馈与决策理由。便于日后回溯与回归测试。

---

## 记录格式（每条三段）

```
[YYYY-MM-DD HH:MM] vX.Y
来源：FB-编号 / 用户访谈 / 内部走查 / 竞品对照
改动：文件 / 接口 / 文案 / 价格 的一句话说明
理由：为什么要改 + 改了预期能改善什么
回归：改完跑了哪些检查（自检 / 用户再测）
```
