## 4. 决策与权衡

- **默认档选择**：选「进阶档 ¥29」而非「免费档」。理由：让客户直接看到付费档的存在与价值，免费档仍可点。
- **进度区命名**：用「推敲/制作/验收」三段而非「step1/2/3」，理由：客户能听懂。
- **价格不动态浮动**：保持明码三档，不引入 bid/拍卖式定价，理由：让客户省心。
