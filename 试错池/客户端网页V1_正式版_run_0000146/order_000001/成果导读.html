想法推进器 · 成果导读

客户一句话 → 推敲 → 制作 → 机器验收 → 归档 → 浏览器拿走成品。

这套网页是什么

「想法推进器」是一台叫 Idea-Pusher 的机器的客户用门面。客户在浏览器里：

  1. 首页一句话写下要做什么（不超过 1000 字）。
  2. 选一档套餐：基础档 免费 · 2 轮进阶档 ¥29 · 4 轮企业档 ¥199 · 8 轮
  3. 提交后，后台写一行进 $TJ_ROOT/logs/queue.txt，并起一个流水线线程。
  4. 流水线：推敲（写 plan.md）→ 制作（按题面关键词分类，写真文件）→ 机器验收（不达标自动重跑，最多到档位上限）→ 归档（zip + 导读 + 账本 + 用量）。
  5. 浏览器结果页有 *_成品.zip 与本导读页直链下载。

本仓库文件清单

  • app.py — 主程序（HTTP 服务 + 流水线 + 自检 + CLI 子命令）
  • README.md — 自己定的规则与理由（定价、流程、口令、归档）
  • 运行命令.txt — 第一行是 TJ_DEMO=1 timeout 10 python3 app.py --selftest
  • 成果导读.html — 本文件
  • 供应商用量_全局.json — 模型用量总账（按供应商、按档位）
  • user_research_plan.md / user_research_questions.md — 用户调研
  • competitor_analysis_plan.md / competitor_analysis_criteria.md — 竞品分析
  • user_test_plan.md / user_feedback_form.md — 原型与可用性测试
  • iteration_report.md / iteration_log.md — 迭代优化

关键命令

  • python3 app.py — 守护模式启动（fork 到后台，写 server.pid 后父进程退出 0）
  • python3 app.py --fg — 前台运行，Ctrl-C 退出
  • python3 app.py --selftest — 自检：起服务 → 走完一单 → 停服务 → 退出 0
  • python3 app.py user_research --plan --questions — 打印用户调研方案 + 问卷
  • python3 app.py competitor_analysis --plan --criteria — 打印竞品方案 + 维度
  • python3 app.py prototyping --design --test --plan --form — 打印原型 + 测试 + 计划 + 表单
  • python3 app.py iteration --report --log — 打印迭代报告 + 记录

价格档位保存在 app.py 的 PRICING 字典里，浏览器点击切换；每次报价落到 logs/ledger.txt 与 logs/usage.json，方便对账。

环境变量

  • TJ_ROOT — 根目录（默认 /opt/tuijinqi，无则自动建）
  • TJ_PORT — 监听端口（默认 8765）
  • TJ_DEMO — 设为 1 自动塞演示单（自检用）
  • TJ_NO_OPEN — 设为 1 关闭自动开浏览器
